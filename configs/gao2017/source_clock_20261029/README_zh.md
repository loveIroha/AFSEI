# 用户确认的首次预加载与后续周期时序

> 本版本预加载通过，正式任务在840.65 ms因固定连接段角部不再被运动封盖覆盖而停止。当前完整两周期改用`source_clock_neck_20261029/`，保留本文时序，只修正连接区下部角部及匹配体积预算；此目录保留历史追溯。

此目录取代先前`upgrade_20261029`中的800 ms舒张加载配置。旧800 ms任务已停止，旧结果不与本次新结果拼接。

| 阶段 | 时序与载荷 |
|---|---|
| 首次0–200 ms | 静态预加载压力由0线性升至8 mmHg |
| 首次200–500 ms | 保持8 mmHg和被动平衡，更新机械畸变历史；EP/GPB/Land ODE冻结 |
| 500 ms | 第一次2 ms电刺激，先等容收缩，达到开口条件后射血 |
| 射血 | 实际出口流量驱动RCR，出口反馈压力；Land计算主动张力 |
| 出流口关闭后80 ms | 冻结接受的空间Ta场，线性降至0；两端闭口，进入等容舒张 |
| 等容舒张期间 | Pc按Q=0继续衰减；左室腔压由等容约束求出，不能另将Pc重复加载到心内膜 |
| 等容舒张结束后0–200 ms | 直接心内膜外加载荷由0升至8 mmHg；流体入口保持0参考压，出口关闭 |
| 随后300 ms | 心内膜载荷保持8 mmHg，入口仍为0参考压 |
| 这500 ms完成时 | 立即执行下一次刺激，进入下一次等容收缩；实际RR由阶段事件决定 |

主动张力卸载以出流口关闭为起点，与用户确认的纯固体源码一致，不使用张力或压力峰值检测替代。

首次预加载仍为既有静态延拓框架，并非模拟0–500 ms的完整瞬态血流。采用100个5 ms的历史采样端点：前40个压力端点进行静态平衡求解，后60个复用同一8 mmHg平衡构形，按原畸变ODE的精确衰减推进Zetas/Zetaw。保持段不重复求解相同有限元平衡，也不将其错误地视为Z历史不变化。

配置`preload.json`重新生成匹配的历史，不能复用之前0–500 ms全程线性升压的缓存。`two_cycles.json`使用新缓存进行两个完整周期，首次刺激固定500 ms，后续刺激在“等容舒张结束＋200 ms升压＋300 ms保持”时执行。

新的直接壁面加载模式不使用旧Gao额外0→12→0 mmHg三角波，也不同时给入口8 mmHg。0参考入口是本次简化加载方案的明确参考压，不等于声称生理左房压力恒为0。

固定源材料、基底罚项、原粗EP/固体网格、MAC128³、NS、基础IB离散、BE–BE及流量驱动RCR仍沿用。共享基底连接和完整三场周期状态记录保留。
