# 左心室：用户时序与基底连接段角部修正

本配置保留已确认的首次200 ms线性升至8 mmHg、300 ms保持、500 ms第一次刺激；出流口关闭后冻结Ta并在80 ms内线性归零。等容舒张结束后，直接心内膜外加载荷用200 ms从0升至8 mmHg，再保持300 ms，随后刺激。充盈入口为0参考压；没有额外12 mmHg三角波。第二次刺激由实际阶段事件安排。

前一份`source_clock_20261029`实验预加载通过，正式推进3438步至840.65 ms，在第一次等容舒张中断。最后接受状态仍严格守恒；下一步固定矩形截面的一小块角部超出运动封盖。零位移初猜也未解决，不能靠初猜或放宽覆盖容差继续。

本轮只修正固定连接段下部的几何：共享基底连接区的外部四个角各去掉一个MAC单元；上部两个矩形通道和实际出口面积完全保留。在上下过渡处补齐不可渗透水平台阶。下部MV/AV截面积分别由2.805664/2.981018变为2.785034/2.960388 cm²；上部仍为原来的2.805664/2.981018 cm²。

体积按“固定上部体积＋运动封盖至固定过渡平面的下部精确积分”计算。下部网格截面分解为互不重叠的矩形，CPU/GPU使用相同P1精确裁剪、离散体积梯度和Jacobian；固定上部体积只计入总量，导数为零。质量预算使用下部颈口和上部真实出口各自的面积。不能直接把原矩形体积公式用于裁角后几何，也不能保留未封闭的台阶底面。

该修正没有改NS、MAC、基础IB、GPB/Land、EP、心肌材料、支撑或BE–BE；没有调整主动张力、RCR参数或求解容差。真实左室正式分支仍为已有`legacy-balanced`压力模式与封盖约束适配，不能称为未经修正的完整Griffith–Luo离散。边界连接形状改变已明确记录。

因为连接几何改变，正式实验重新生成匹配预加载，不从旧流场中途拼接。新预加载已完成100个历史端点，40个静态升压平衡点与60个保持端点；总时长500 ms，初始LV容积138.0140 mL。保持段按原畸变ODE更新历史，不重复求相同静态平衡。

实际CUDA验证：新颈口与原矩形回归共14项通过。失败点附近840.65–841.65 ms的10个短步均通过，最大质量误差4.09e-10 mL/s。该短段使用旧场作为改变几何后的诊断初值，只用于验证失败位置，不作为正式周期的一部分。
