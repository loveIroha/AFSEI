# Gao 连接位置对齐：截断边界短程验证

本目录用于验证循环压力从内部基底圆盘迁移到固定通道末端的实际 MAC 外边界，不是已验收的两周期配置。服务器根目录为 `/mnt/large2/gjh/AFSEI`。

## 方程与作用位置

`cut_plane.CutPlaneFlow` 在物理半网格边界给定压力，通过原有 BE 黏性预测和 MAC 压力投影计算响应。RCR 使用通道末端实际面流量，而不是用固体体积变化生成替代流量：

    C (Pc_new - Pc_old)/dt = Q_cut - (Pc_new - Pv)/Rp
    P_cut = Pc_new + Rc Q_cut

利用线性流体响应消去一个标量边界压力，Pc_old 在同一非线性时间步内保持不变；只有流固步被接受后才发布新 Pc。力学 Jacobian 使用包含同一 RCR 阻抗的齐次流体响应。

基底 MV/AV 两个连接口的压力乘子均设为零，两个口都与各自通道连通。瓣口开闭条件放到物理通道末端，非端口基底区域继续使用原有约束及配对反力。心内膜不额外叠加 P_cut。固体本构、EP/GPB/Land、主动张力与人为卸载保持原配置。

Gao 的模型在固定流入/流出道顶部连接循环模型。本分支只对齐这一连接位置和压力含义；几何仍是本项目的理想化通道，不是 Gao 的患者几何或完整瓣膜模型。[Gao et al., 2017, §2.4](https://eprints.gla.ac.uk/143010/1/143010.pdf)

## 明确的数值约定

- 原有时间格式为 BE–BE，MAC 压力投影及多重网格保留；新增固定分隔面的法向速度为零。
- 压力边界沿用现有投影法的“压力 Dirichlet / 预测速度 Neumann”约定，不声称已经实现非分裂的完整对称应力牵引边界。
- 固定通道沿基底法向最接近的正 MAC 轴建立。截面积、长度、阶梯壁面和切向处理全部写入报告；普通 FE/IB 心肌仍由原求解器推进。
- 固定通道几何由一个预加载快照统一锚定；短程来源快照或时间步回退不会重新改变通道尺寸。
- 既有开盒压力模式的解析零速度叠加依赖原边界条件，不能直接搬到有固定隔壁的新域。新分支保留功共轭配对，但对该项计算完整流体响应，并同步修改 Jacobian。
- 将原有全局压力模式的守恒对象由单独 LV 改为 LV 加两个连接通道。用 P1 基底与固定通道截面的精确裁剪积分计算通道体积，离散梯度满足有限步体积增量。该项是新的压力接口离散适配，不能声称数值耦合算子逐项未改。没有增加全局未知压力、额外约束或外层强耦合迭代。

## 验证与状态

GPU 检查已通过：4 项切面压力/RCR/功率/预条件器检查，3 项精确通道体积、离散梯度、完整几何 Jacobian 及脱离检查。最后另行检查原压力参考、舒张载荷、Gao 阶段逻辑和标准 IB 端口，共 31 项通过。

真实 LV 的最终验证结果：`results/gao_cut_validation_20261026/filling_conservative` 接受 1 步至 1400.0 ms；`ejection_conservative` 接受 3 步至 664.7 ms。两组使用同一份预加载状态锚定固定通道几何，均满足原非线性残差、质量、功率和 RCR 检查。修复前的丢弃式试算保留在同一父目录下。

通道末端是固定面，基底口是移动面，两者的相对流量不必相等。正确的整体平衡为：

    (ΔV_LV + ΔV_MVtract + ΔV_AVtract)/dt + Σ Q_cut,outward = 0.

另行严格检查固定通道底部与末端的有限体积通量相等。不能把基底口的插值通量误差或通道储存项当作 RCR 压力。

验收条件包括原始非线性残差、总体质量、关闭端口流量、边界功、RCR 平衡，以及新增的通道末端与基底流量一致性。不能通过放宽检查或直接扣减腔压让实验通过。

这两个 JSON 由 `scripts/check_afsei_cut_boundary.py` 读取。脚本只做丢弃式短程试算，不覆盖旧周期结果，也不保存可被误当作普通周期的检查点。循环重启模块明确拒绝保存尚未扩展几何格式的该分支。

本轮上述短程验证已通过，但仅覆盖充盈 0.1 ms、射血 0.3 ms，尚未验证完整周期、阶段切换、全程固定通道连接和新几何下的预加载。没有将它改成生产默认，也没有启动完整两周期；旧的两周期命令仍使用旧接口。
