# 物理截断边界与有限步质量/功率配对

这是 AFSEI 对新增压力接口的离散适配，不是声称 Gao 文献采用了下面的全局修正。NS、EP、GPB/Land 和心肌本构方程不因本适配改变。现有 FE/IB 转移保留一个功共轭的全局压力模式；它的控制体积从 LV 改成 LV 加两个固定通道，未增加压力未知数、额外约束或外层 FSI 迭代。

令 W 为 MAC 面速度的体积权重，S/J 为基础 FE/IB 转移。gbar 是总血液几何体积 V=VLV+VMVtract+VAVtract 的离散梯度，满足

    gbar : (x_new-x_old) = V_new - V_old.

LV 的 P1 闭合体积采用原有 Simpson 离散梯度。通道体积是固定矩形截面与移动 P1 基底扇形面之间的精确裁剪高度积分，用中点梯度加割线修正满足上述等式；Newton 线性化包含这项修正的导数。

令 Bc/Kc 分别为非端口基底封盖的流体/材料通量行，Bout 为所有开放物理截断面的外向通量行。两处基底端口本身均不施加压力跳跃，瓣口关闭在通道末端实现。取 C=1333.22368421，定义

    m = C (Kc^T 1 - gbar),
    tau = GD psi + W^-1 Bc^T (C 1) + W^-1 Bout^T (C 1),
    a = m / (m:m).

GD 是含固定面掩码的零 Dirichlet MAC 梯度。psi 沿血液通道延伸到截断面邻近单元，取值 C。GD psi 在物理边界的半网格项与 Bout 的升压项互相抵消，tau 的合成边界面值为零，避免把一个额外压力载荷叠加到 RCR 边界。

采用同一冻结构型的配对

    T f = S(f - (a:f)m) + (a:f)tau,
    I u = J u + a [tau^T W u - m:J u].

于是 T/I 严格功共轭。对于满足 D u=0 的速度，GD 的离散分部积分给出

    tau^T W u = C 1^T Bc u + C 1^T Bout u.

结合非端口封盖的 Bc u=Kc Iu 与 x_new-x_old=dt Iu，得到

    (V_new - V_old)/dt + sum(Q_cut,outward) = 0.

RCR 直接使用实际 Q_cut，旧 Pc 在非线性迭代中固定，新 Pc 仅在完整流固步接受后发布。边界力和电路均使用同一压力和流量计算功率。

因此可同时严格检查总几何体积、固定通道有限体积通量、FE/IB 功率及 RCR 平衡。基底移动面的插值相对流量仍是独立诊断量，不可误当成固定截断面的实际流量。

本分支仍沿用 BE 黏性预测及压力投影的边界约定，不等同于非分裂的对称应力牵引离散；固定通道也不是 Gao 患者的真实流出道。正式周期入口及重启格式仍需后续接入。
