# 固定流道的加载历史、阶段控制与重启

本分支显式选择 `CutCardiacStepper`；已有两周期命令的默认连接不变。此处保留源材料、EP/GPB/Land、基底罚弹簧和 BE 时间格式，继续使用此前验证的 MAC 固定流道压力接口。

## 加载历史

`full_loading.json` 指向既有完整粗 EP 运行的配置/网格，几何锚点为同一预加载快照。按 0–500 ms 的压力斜坡生成 100 个物理加载采样点。每点求解

    f_material + P ∂(V_LV + V_MVtract + V_AVtract)/∂x = 0.

EP、GPB/Land 门控和 Windkessel 时钟不在数值延拓中推进。伸长及 Zetas/Zetaw 使用原 `SourceLoadingHistory`，按 5 ms 的物理采样间隔更新；不把数值 Newton 迭代当作物理时间步。

`preload_history.npz` 记录最终几何、伸长、两组畸变历史、固定流道锚点、100 点加载报告、配置和网格绑定及数据校验和。不是把旧预加载状态简单投影到新几何。

## 阶段与压力

- 等容收缩：两个物理截面关闭，流道与腔体内部仍连通；动脉电容按零出口流量衰减。关闭 AV 的上游流体压力超过动脉状态后，下一时间区间开放 AV。
- 射血：实际 AV 截面流量驱动 RCR，压力返回同一截面；不在基底端口额外施加压力跳跃。
- 当开放支路试算出现反向出口流量，丢弃该支路，从同一旧状态重新计算关闭支路；只发布一个接受的端点。它是发生开闭事件时的分支选择，最多两次支路求解，不是每步添加外层流固强耦合迭代。
- 关闭出口的接受端点调用原 `publish_outlet_closure`，保留按已求解张力快照触发的 80 ms 人为卸载。
- 等容舒张：两物理截面关闭，满足卸载结束及上游压力条件后进入充盈窗口。
- 充盈：保留原 Gao 独立入口与腔壁压力波形；即使 MV 暂时关闭，阶段定义的腔壁波形仍有效。MV 按物理截面流量和关闭上游压力开闭。第二次刺激仍在 1400 ms，原 100 ms 恒压尾段保持。

压力比较和开闭事件在接受端点处理，符合现有一阶 BE 推进精度；未引入子步内瓣口事件根搜索或真实瓣叶。

固定截面与移动基底之间会储存血液，因此关闭阶段守恒对象是 V_LV+V_tract，累计质量平衡也使用这个总量。输出同时保留左心室容积、流道储量、实际截面流量，不能用基底插值流量代替 RCR 的输入。

关闭端口时，日志记录上游流体压力并标记 `closed-upstream-fluid-trace`；开放时记录施加的物理截面压力。两者不会与零内部压力面乘子混淆。

## 重启

新生产者标识为 `afsei-mac-physical-cut-four-phase-v1`。新重启包含固定流道锚定几何、预加载历史校验和、总血液参考体积及原 EP/ODE/力学/卸载历史。普通试算分支仍不能冒充完整加载的周期检查点。

原格式继续按原连接读取；新格式只有 `cardiac=True` 的周期读取接口识别。校验失败、加载记录不全或配置不一致时拒绝恢复。初始与推进后重启都应在真实 GPU 上验证。

## 运行

使用 afsei 环境，在项目目录运行：

```bash
python scripts/prepare_gao_cut_loading.py configs/gao2017/connection_pair_20261026/full_loading.json
python scripts/run_afsei_cut_cycle.py configs/gao2017/connection_pair_20261026/cut_cycle_short.json
```

输出目录必须不存在。已经算好的 `preload_history.npz` 可直接复用，不应重复计算 100 点加载。短段配置只推进 2 ms，不会自动运行两个完整周期。

后续恢复配置使用 `resume`、`output` 和可选 `duration_ms`；不再提供新加载或循环参数覆盖。恢复必须沿用检查点内的固定流道和物理历史。

完整周期的实际瓣口切换、射血压差和两周期 EF 仍需后续物理验证；阶段控制测试及刺激后 2 ms 验证不能替代这些结果。当前不将它设为既有最佳性能两周期方案的默认入口。

## 已完成的验证与执行优化（2026-10-26）

100 点真实加载历史已完成并缓存，静力残差 1.99e-4 dyn。随后 500–502 ms 的真实 EP/流固推进和初始、推进后重启检查通过；此段只覆盖等容收缩，发生过一次自适应回退，不能替代后续开阀和射血验证。

新配置项 `tract_geometry_gpu: true` 将流道体积的裁剪交点、离散梯度及精确 Jacobian 移到 GPU。它保留原来的 P1 几何、割线功一致性修正和 Newton 导数。仅缓存裁剪分支拓扑，每次检查分支；变化时重建，分支歧义时回退原实现，不冻结交点或梯度。选项随检查点保存，旧检查点默认关闭。

同一 502 ms 检查点的三个 0.05 ms 接受步，使用既有 CPU 结果作为基准，不重复基准计算：

| 指标 | CPU 几何 | GPU 几何 |
|---|---:|---:|
| 去首步后平均时间（仅后两步） | 11.806 s | 3.659 s |
| 包含初始/末尾重启的本轮总时间 | 100.688 s | 74.592 s |
| 新增回退 | 0 | 0 |
| 最大质量残差 | 2.10e-9 mL/s | 1.56e-9 mL/s |

两组 Newton 迭代数与流体求解调用次数相同。位移最大差异 1.78e-15 cm，压力最大差异 1.45e-7 dyn/cm²，电位最大差异 8.33e-17 V。GPU 分支的初始及推进后重启通过。短样本去首步加速约 3.23 倍，含初始化总时间约 1.35 倍；不能据此预测完整周期总耗时。

只读微基准中，77 个基底节点的几何 Jacobian 从 1.630 s 降到 0.0492 s。另一可选项 `pressure_compact_geometry` 只对可无损表示的几何系数压缩存储，场量与运算仍为 FP64；压力微基准约提升 9%，但整步短测未见明确收益，因此保持关闭。

短程 GPU 几何验证配置为 `gpu_geometry_step.json`，其输出已经存在，请勿重复运行覆盖。下一项是实际开阀、射血及卸载转充盈的物理验证；当前没有新的完整两周期 EF，也没有证明历史约 50 mmHg 的腔内—出口压差已消除。

## 开阀前求解失败的精度修复

首次延长实验在 513.5 ms 后因 Newton 回溯失败停止，尚未开阀。511.7 ms 检查点的定点诊断显示：固定初值的残差重复差异约 1e-13，Jacobian 与中心差分相对差约 4.7e-8；原内层压力精度下，不同求解历史的截断误差能影响外层 1e-9 接受判断。

新配置项 `cut_pressure_solver: {"rtol": 1e-12, "atol": 1e-14}` 仅收紧该分支的压力 PCG 精度；不改变压力算子、多重网格、MAC/IB、BE 时间推进或外层 Newton 阈值。省略时保留原精度，旧运行入口默认不变。该项写入并恢复检查点，配置不允许放宽继承的原压力容差。

`strict_pressure_crossing.json` 已完成 511.7–514.2 ms 的 25 个 0.1 ms 步，零新增拒绝，初始及末尾重启通过。最大质量残差 4.09e-10 mL/s。与旧实验重叠的 18 个时刻，LV 容积差最多 1.52e-11 mL、腔压差最多 0.000441 mmHg。此次通过的是原失败位置的短段，并非完整开阀或周期验证。

新的首次开阀实验使用 `strict_pressure_first_opening.json`，从 514.2 ms 继续，开阀后再计算 2 ms 自动停止，最多继续 120 ms。任务已在 GPU0 后台启动，输出目录为 `results/gao_cut_cycle_validation_20261026/strict_pressure_first_opening/`。不要重复启动。

若再出现失败，运行入口将额外保存最后已接受的物理检查点，以及带明确未接受标记的 Newton 诊断向量。后者不能作为物理状态重启。
