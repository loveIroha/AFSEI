# 单基底物理流口：实施状态

采用一个基底双向流口，不建瓣叶、共享连接段、虚拟封盖乘子或全局压力模态修正。阶段控制保留纯固体逻辑，充盈的心内膜人为载荷与流体参考压分开记录，射血后负荷只施加在流口。三元RCR保持原BE电容方程和trial/commit语义。封闭及充盈阶段以Q_AV=0推进动脉电容压力，不冻结动脉压力。

## 已实施

- 新建EP默认方向映射为l2-cg1；fiber/sheet经一致质量L²投影和正交归一化，normal用叉积。新建EP默认求解器为torch_pcg_jacobi_light，保留nodal FEM/CN。
- 历史checkpoint仍按保存设置解析，缺省字段恢复历史含义；不能把旧结果当作新配置结果。
- scripts/run_afsei_cycle.py和run_afsei_cut_cycle.py的旧LV周期入口已停用，避免继续使用封盖/延长流道/压力模态路径。历史代码和结果保留用于审计。
- single_port.py提供一个真实MAC外边界开口的开/闭及RCR响应组件。没有心肌附加载荷、封盖乘子、体积梯度修正或更换IB散布/插值算子。
- phase_direction_valid明确报告射血返流或充盈逆流；未来周期控制器必须据此进行事件定位/关闭，不能把通量直接截为零而不重算流体。

## 尚未完成，不是可运行全周期配置

当前原始IB积分点/四点核需要完整背景网格支撑，现有代码把结构放在盒子内部。把物理边界直接移到原基底面，会截断靠近基底的核支撑，不能通过取消support检查或继续使用旧流道解决。

必须先落实物理边界处的核/虚单元处理，使有效散布和插值仍为功共轭的一对，并验证参考压力与内外域的关系；这属于必要的边界适配，不是已实现或已验证的功能。单流口组件测试不代表真实LV边界问题已解决。

随后才能接入原AFSEIStepper的BEIBStepper、纯固体压差阀门/阶段事件和80 ms卸载，做同配置预加载，再完成阶段短程验证。旧预加载速度和旧循环checkpoint均不能直接复用。

尚未提供两周期运行命令，尚未启动新LV模拟。ep.json只配置EP数值方法，不包含可运行LV几何/边界或循环驱动。
