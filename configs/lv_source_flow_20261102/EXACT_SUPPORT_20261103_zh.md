# 基底支撑接入与真实左心室单步验证

## 修改

新增 mac/basal_support.py，显式选择 enable_basal_support(driver)。原默认流程保留。
每个基底顶点约束参考环向及全局 z 向位移，径向自由；心尖无支撑。
964 个支撑反力未知量与原位移一起通过隐式 Newton 求解：

```
y - dt*J*H(S*(F(X+y)+B^T*lambda)) = 0
B*(X+y-Xref) = 0
```

B 提取基底环向和纵向分量；B^T lambda 是积分节点反力，单位 dyn。
使用原 Griffith–Luo 散布/插值对、原流体求解器、原 BE–BE 推进。
没有夹断位移或覆写速度，没有腔体封盖/体积乘子或全局压力补偿。
这里的乘子代表用户要求的物理基底支撑；区别于此前为封盖体积引入的额外约束。
节点位移约束按 P1 节点施加；不能称为逐点完全相同于原有限刚度罚弱式。

旧罚弹簧必须显式 beta=0 后重新构造模型，避免重复支撑。反力变量按 rho*节点参考体积/dt^2 缩放仅改善量纲，不是新增材料刚度。
只支持 assembled Newton；目前没有增强系统预条件器，必须选择 none。
启用时旧检查点若不满足强支撑会被拒绝，不能投影旧几何以掩盖漂移。

## 验证

- tests/test_exact_basal_support.py：CPU/GPU 均通过，结果与独立直接求解的鞍点系统一致；径向自由、心尖自由、反力虚功、完整切线有限差分通过。
- 原 BEProblem 缓存回归测试通过。
- scripts/check_real_lv_support.py：GPU1，原 LV 26889 节点/135430 单元，原 128^3 MAC，dt=1e-4 s，从参考构型施加 0.1 mmHg，单步通过。

## 范围与后续

这是物理支撑正确性验证，不是压力8–200 mmHg下的全周期验证，也未连接流道或推进 EP。
结果目录：results/real_lv_support_20261103/report.json。
未加入支持新反力状态的完整周期重启功能，不能从旧检查点直接续算。
该实现暂不适合作为生产性能配置；280次GMRES显示需要增强系统预条件器。
固定流体连接结构及径向滑移衔接仍未完成，完整周期未启动。
