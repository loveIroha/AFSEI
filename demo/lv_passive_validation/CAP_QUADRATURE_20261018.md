# 基底盖面高斯积分修改与验证

本轮完成盖面流量/压力积分精度修改，保留原 MAC、统一有限元 IB、BE–BE 及原有限元心肌模型。
正式周期的质量验收阈值保持不变；当前标准路径仍未通过完整周期验收。

## 实现

`MACBasalPorts` 新增 `integration_rule`：`centroid`、`gauss3`、`gauss7`、`gauss12`。
后面三种分别在原子三角形上使用正权三点二次、七点五次、十二点六次三角形积分。
原 level-4 子三角形、MV/AV 区域标签及压力分区的代表位置都保留。
增加的是每个已有子三角形内部的积分点，没有增设压力约束。

`prepare_local_cap` 按原子三角形确定压力分区，再将同一压力分配给它内部的高斯点，
使流量行 B、流体压力反力 -B^T p 和材料反力 C^T p 使用同一积分定义。
`CompactCapRows` 继续从这些行生成紧凑算子，不另造一套权重。

`BalancedAFSEIStepper` 和检查点明确保存 `cap_integration_rule`。
旧检查点缺少此字段时恢复为 `centroid`，保持其历史含义。
新启动的周期可在 `--spatial-config` JSON 中明确选择新规则。
默认与旧历史仍为原规则；没有把未通过周期验收的候选静默设为默认。

## 同一保存速度场的积分比较

使用前一轮已保存第 201 步的速度与旧交互几何，以已经收敛的盖面细积分为参考。
前三种测量完成后仅补测十二点规则，没有重新运行它们或重跑流固步骤。

| 规则 | 盖面流量相对细积分差额绝对值 / mL/s | 压力未知数 | 盖面积分点数 | 盖面算子准备时间 / s |
|---|---:|---:|---:|---:|
| 原质心 | 0.111888999 | 201 | 19712 | 0.03042 |
| 三点 | 0.031255935 | 201 | 59136 | 0.04118 |
| 七点 | 0.001285020 | 201 | 137984 | 0.07041 |
| 十二点 | 0.0000455894 | 201 | 236544 | 0.10743 |

十二点相对该参考的差额减少约 99.96%，满足本次诊断 1e-3 mL/s 目标。
参考自身最后一次加密变化为 8.46e-5 mL/s，所以不能据 4.56e-5 这个差额宣称绝对误差已达到该量级。
表中准备时间只覆盖盖面算子准备，不包括完整流固步；这些短测量不是完整周期性能基准。

真实盖面所有规则的压力未知数均为 201，压力分区映射一致。
十二点规则的最大分区面积变化约 1.60e-15 cm²、材料通量变化约 1.22e-15 mL/s，
配对功相对误差约 1.04e-16。

## 实际隐式耦合的三个新步

从 `lv_passive_standard_hold_20261017` 已保存的第 200 步状态分支，
仅更改盖面积分为十二点，新增第 201–203 步，共 0.3 ms。
原 200 步记录保留原质心方法，其历史没有被重新标成十二点结果。
`continuation.json` 明确记录新积分从第 201 步开始。

| 指标 | 原质心，第 201 步 | 十二点，第 201 步 |
|---|---:|---:|
| 物理时刻 / ms | 20.1 | 20.1 |
| 瞬时体积预算差额 / mL/s | -0.332601109 | -0.220044534 |
| 腔体积 / mL | 105.063184706 | 105.063139236 |
| 入口流量 / mL/s | 87.81581404 | 87.24856477 |

同一时刻的预算差额绝对值减少约 33.84%。三个新步均接受，没有步长回退。
第 202、203 步的差额分别约 -0.221331、-0.222407 mL/s；
最后一步的配对功相对误差 1.70e-13，闭合盖面通量残差范数 4.81e-12 mL/s。
其余空间误差仍在，不能把盖面单项的 99.96% 改善套用到总预算或射血分数上。

首步耗时 32.61 s，随后两步为 4.00、3.83 s；三步总计（含初始化）46.70 s。
样本不足以量化完整周期性能变化，也不据此计算加速比。

## 剩余问题

十二点规则下，冻结预加载的固体相对力残差仍约 5.80e-11，
MAC 力密度非梯度范数比例由 9.011% 变为 9.006%，基本没有改善。
因此盖面积分修改没有解决预加载压力交接的主要兼容性问题。

总瞬时预算差额约 0.22 mL/s，仍高于正式周期 1e-5 mL/s 的原有验收阈值。
这次修改只解决盖面积分中的一项误差；标准 IB 的有限元投影与核插值仍需继续做分辨率/一致性检查。
没有增加全局修正、局部约束或调整主动张力来掩盖剩余差额。

## 验证与使用

本轮新增并通过 16 项相关测试：三点/七点路径 9 项，随后只补跑十二点路径 7 项。
覆盖 CPU/GPU 多项式积分、扭曲盖面的分区保持、两侧功配对、解析切线有限差分及两种流体解法的检查点恢复。
已有质心实验没有重跑。

诊断配置：`configs/standard_gauss12_hold.json`。
可供后续验证的周期空间配置：`configs/production_standard_gauss12_candidate.json`，
使用 `be-projection`、标准 IB、多重网格及十二点盖面积分。它仍是候选，尚未通过正式周期验收。
原联立 Stokes 候选保留用于对照，没有据本次结果把它设为优先解法。

复现实验入口（不需要为本次结果重新执行）：

```bash
python demo/run.py demo/lv_passive_validation/configs/standard_gauss12_hold.json \
  --diagnostic-resume results/lv_passive_standard_hold_20261017 \
  --cap-rule-trial --audit-budget --output results/NEW_UNIQUE_DIRECTORY
```

`--cap-rule-trial` 仅允许在诊断分支上明确改变盖面积分；正式周期续算仍从检查点恢复方法。

服务器结果：

- `results/lv_cap_rules12_20261018/cap_rules_audit.json`：同场积分与配对对照，含复用来源。
- `results/lv_gauss12_trial203_20261018/`：三个新增耦合步、预算分解与方法切换记录。
- `results/lv_gauss12_static_audit_20261018/static_force_audit.json`：修改后冻结预加载审计。
