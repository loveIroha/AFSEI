## 1. 体积预算差额主要在哪一层

采用血液外向为正。实际检查量为

\[
B=\frac{V^{n+1}-V^n}{\Delta t}+\sum_i\bigl(B_i u-C_i v\bigr),
\qquad v=(x^{n+1}-x^n)/\Delta t.
\]

这里 `B_i` 是实际流体盖面通量行，`C_i` 是其材料速度积分行。
定义旧几何的精确闭腔体积梯度为 \(g=g_w+g_c\)，沿本步直线位移精确积分的梯度为 \(\bar g\)，
\(c=\sum_i C_i^T\)，实际有限元投影速度为 \(w=Ju\)。则

\[
B=(\bar g-g)\cdot v+(g-c)\cdot(v-w)
 +(g_c-c)\cdot w+\left(g_w\cdot w+\sum_i B_i u\right).
\]

该分解只用于观测，不进入任何残差、切线或载荷。

第 201 步，dt=1e-4 s，入口流量约 87.81581 mL/s：

| 项 | mL/s |
|---|---:|
| 一步内几何变化，旧构型到扫掠构型 | -0.00199951055 |
| 运动方程残差 | +2.70785e-9 |
| 盖面材料积分与精确几何积分差异 | +5.24407e-16 |
| 空间传递与流体盖面通量不一致 | -0.33060160228 |
| 总预算差额（包括所有盖面行） | -0.33260111013 |
| 分解闭合误差 | -9.90e-13 |

空间项占该步预算差额绝对值约 99.40%，几何时间项约 0.60%。
总差额约为本步入口流量的 0.379%；这不是整个周期体积损失的百分比。
收紧 Newton 或压力迭代、单纯减小 dt，均不是针对本步主要差额的优先措施。
本步是续算后的一个局部样本，尚未建立整个周期或网格收敛规律。

## 2. 空间项进一步分成三个来源

在实际使用的旧交互几何上，将上述空间项写为

\[
\underbrace{\int_{\Gamma_w}w\cdot n-\int_{\Gamma_w}u_h^\delta\cdot n}_{\text{FE 体积投影后的壁面迹差异}}
+\underbrace{\int_{\Gamma_w\cup\Gamma_c}u_h^\delta\cdot n}_{\text{核插值后的闭合通量}}
+\underbrace{\sum_i B_i u-\int_{\Gamma_c}u_h^\delta\cdot n}_{\text{实际盖面算子与精细积分差异}}.
\]

\(u_h^\delta\) 使用原四点 Peskin 核，未换成新插值方法。
最后一项使用完整盖面总和，因此此处不会把真实的开放入口流量当成漏流。

| 来源 | mL/s |
|---|---:|
| FE 投影壁面迹差异 | -0.11555365202 |
| 核插值场的闭合表面通量 | -0.10315895141 |
| 生产盖面积分与精细表面积分差异 | -0.11188899886 |
| 合计 | -0.33060160228 |

三项均有贡献，不能只归咎于有限元投影或只归咎于压力投影。
壁面 level 2 → 3 的通量变化为 1.38e-5 mL/s；保持该壁面结果后，盖面加密至 level 6/7，
最后变化为 8.46e-5 mL/s，满足本次诊断 1e-3 mL/s 的积分稳定目标。
这是诊断积分精度，不是生产质量验收放宽。

独立 RT0 迹的闭合通量仍约 -0.00281 mL/s；其壁面积分尚未单独收敛，
不能把这一数值当作精确的 MAC 质量损失。RT0 未用于实际壁面运动。
壁面绝对法向相对通量约 6.94 mL/s，是正负局部差异的绝对值积分，也不能当作净流失量或射血量。

## 3. 预加载：固体已经平衡，但传播后的力不是纯离散压力梯度

使用原 138.3227158 mL 预加载构型和 8 mmHg，对被动/基底力加原内膜与配对盖面压力载荷：

| 指标 | 数值 |
|---|---:|
| 固体节点残余力 L2 / dyn | 2.05513e-6 |
| 规定压力节点力 L2 / dyn | 35412.71347 |
| 固体相对力残差 | 5.80338e-11 |
| 盖面反力与解析几何载荷差 / dyn | 4.45819e-12 |
| MAC 力密度非梯度部分的加权范数比例 | 0.09011048 |
| 假设固体精确平衡后，力密度相对改变 | 1.20957e-10 |

通过原 MAC 压力算子求解 \(-DGq=-Df\)，得到 \(f-Gq\)。
约 9.01% 是该非梯度部分与总力密度的加权范数比，不是压力误差、流量误差或体积损失率。
这说明在当前固定几何和标准传递下，仅把固体预加载 Newton 求得更精确，或者仅修改初始压力场，
不足以消除静态残余驱动。
该审计针对瞬时 MAC 力平衡；分步 BE 的精确制造平衡还涉及 \(HGp\)，不混淆两者。

此前第 23 阶段已观察到相近的孤立载荷问题，本轮没有重跑其所有核函数实验。
本次新增证据针对现有配对盖面、当前预加载状态及已迁移的标准 IB 路径。

## 4. 修改优先级与边界

1. 首先提高基底盖面的流量/压力积分精度，同时保持流量算子、流体压力反力和材料反力的配对关系。
   应保留端口分区与闭合约束的含义；不能只改流量计算而留下旧的反力。
2. 对 FE 投影与核插值分别做空间分辨率检查，区分 FE 空间误差、交互积分误差与 MAC 分辨率误差。
   本轮尚未证明加密哪一种网格能以最低成本消除它们。
3. 静态交接必须以标准 IB 的实际流固离散重新检验；不要用调整主动张力来补偿被动交接问题。

Griffith–Luo 2017 同时讨论 unified 与 partitioned 两种形式。
文中指出统一形式会把表面力投影到体积 FE 空间；分区形式在部分粗结构网格算例中改善体积保持，
但不具有文中统一形式的离散功恒等式。因此不能把分区形式视为无代价替换。
本轮仍保留统一形式与 BE–BE，没有擅自引入另一种耦合。
[原论文第 3 节和结论](https://arxiv.org/html/1612.05916)。

这些结果主要解释标准 IB 迁移后的验收障碍。历史两周期使用的是带全局预算修正的旧路径，
不能把本次标准路径的差额直接认定为历史射血/回填不足的原因。
历史充盈时序与压力历程的证据仍成立；历史收缩不足仍需另行检查。
标准路径尚未通过完整周期验收。
