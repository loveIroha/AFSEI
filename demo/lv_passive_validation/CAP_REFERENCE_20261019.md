# 壁面升压的盖面压力基准闭合（2026-10-19）

本轮复用已有周期和预加载状态，修正直接壁面载荷与人工基底盖面之间的压力参考。NS、BE–BE 时间格式、MAC 压力求解器、IB 传递、EP/GPB/Land、心肌本构及 80 ms 人工张力卸载未更换。没有运行新完整周期。

## 已确认的不一致

当前预加载由被动/基底力、8 mmHg 内膜压力和配对盖面反力共同平衡。上一版壁面充盈只保留内膜压力，入口改为零表压，没有补齐同一盖面的压力参考力。

在同一个 138.3227158022 mL 预加载构型上，不推进时间的检查为：

| 冻结条件 | 入口净流入 mL/s | 最大速度 cm/s |
|---|---:|---:|
| 原入口8、壁面0 | 6.07e-11 | 1.39e-9 |
| 旧壁面8、入口0 | -2.38164 | 1.85725 |
| 壁面8＋盖面参考8、入口0 | 1.15e-10 | 1.29e-9 |

这是同构型的冻结 BE 流体响应，未更新弹性力，不是完整时间步。被动＋内膜力残差为 26863.16945 dyn，对应被遗漏的盖面压力力；加上配对盖面后残差为 2.05e-6 dyn。

## 修正方程及范围

`Pw` 为规定壁面升压，`lambda` 为原盖面压力乘子，`Ccap/Bcap` 为已有材料/流体通量行。新配置采用

    F = Fpassive + Factive + Fendo(Pw) + Ccap^T (lambda + Pw * 1)
    fluid forcing = T F - W^-1 Bcap^T lambda
    q = Bcap u - Ccap v

充盈入口仍规定 `lambda_MV=0`。增加项使用同一盖面几何、积分和材料反力算子；没有增加压力未知量、局部运动约束或完整 FSI 外迭代。BE 步内盖面仍按原方法冻结，新增参考力没有新的位移切线；内膜 follower 力保留原精确切线。

在冻结构型的当前 legacy-balanced 传递下，将全部盖面乘子减去 `Pw`，同时加上闭合表面的规定压力力，剩余流体右端不变，只改变已知压力势的参考。独立非平衡测试的剩余右端相对差为 4.21e-16，势幅值变化精确为 -6.3 mmHg。这不能扩大为所有 IB 离散的通用结论。

RCR/等容阶段两项规定载荷都为零，原方程继续适用。检查点保存 `wall_pressure_mmhg` 与 `cap_reference_mmhg`，包括最后一个充盈步刚发布起搏事件的情形；下一物理步再切换载荷。单独输出盖面参考力的功率，原盖面乘子功伴随检查不变。

## 高压差与充盈不足的剩余证据

保存终态的原始传递与修正插值所得容积率差，新/旧分别为 -0.23689、-0.05801 mL/s；修正速度L2比例约0.0291%、0.00469%。这不能解释为已经证明收缩峰值时修正也小。

已有560 ms收缩状态，腔内核心103.202、出口乘子84.645 mmHg；压力分解为已知势88.715＋剩余压力14.487 mmHg。已知势包含材料与盖面力投影，不能把它全部称为人工错误压力。本次周期的峰值时刻没有完整场快照，仅有标量记录，尚不能定量归因117 mmHg的峰值差。

端口在参考构型标记，随基底运动，面积并非恒定：

| 状态 | MV当前面积 cm² | AV当前面积 cm² |
|---|---:|---:|
| 新结果2100 ms | 0.96191 | 0.50319 |
| 旧结果2100 ms | 1.35074 | 0.69403 |
| 已有早期收缩检查点560 ms | 1.74825 | 0.88881 |

新终态MV面积比旧终态小约28.8%，而面积平均相对法向速度接近：65.24对63.11 cm/s。这个不同状态比较不是单因素因果试验，但说明应将端口面积与流量一起分析。

按AV参考面积pi*0.4²=0.50265 cm²与峰值流量229.67 mL/s估算，Q/A约4.57 m/s；项目rho=1 g/cm³对应动压尺度约78.3 mmHg。但当前峰值面积没有保存，560 ms实际面积是0.88881 cm²，故不能把78.3 mmHg当成已测实际峰值压降。还需考虑非定常加速、IB正则化和端口反力；几何面积不是临床有效瓣口面积。

速度平方压差关系及其忽略非定常、黏性和上游速度的条件，可参考 [EACVI/ASE 2017指南第6页](https://www.asecho.org/wp-content/uploads/2017/04/2017ValveStenosisGuideline.pdf)。本轮没有改变端口半径，也没有按临床阈值将数值端口判断为解剖瓣膜狭窄。
