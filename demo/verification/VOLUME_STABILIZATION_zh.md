# 三维圆管体积稳定化：实现、短程验证与从静息后续计算

本轮新增默认关闭的体积稳定化选项，并完成两档固体上的 60–100 ms 开关筛选。短程筛选通过：壁体积误差明显降低，电位、钙与 Land 张力输入保持一致，圆管继续明显收缩。另两组从静息开始的 0–300 ms 验证已启动，完成前不能将本轮结果称为完整轨迹空间收敛。

## 1. 实际修改了什么

保留 NS、原 MAC 网格与差分、多重网格压力投影、Griffith–Luo 统一积分点 IB、一致质量传递、BE–BE、Newton–Krylov，以及原 EP/GPB/Land 和端部支撑。新增内容位于圆管的附加应力回调中，显式选择时才启用。

令原附加 PK1 应力为 P_old，其中包括原 Neo-Hookean 被动项和原环向 Land 主动项。定义

    J = det F
    U(J) = κ_stab/2 · (ln J)²
    P_new = P_old − (P_old:F)/3 · F⁻ᵀ + κ_stab ln(J) F⁻ᵀ

对应的附加 Cauchy 应力为

    σ_new = dev(σ_old) + κ_stab ln(J)/J · I

这是文献中的**偏量应力投影＋对数体积稳定化**，不是 Flory 等容能量修改。它保留原附加 Cauchy 应力的偏量，替换球形成分。GPB/Land 的状态更新、张力幅值与时钟不变；最终传给流体的 PK1 会因投影而改变，不能称为节点力逐项不变。

稳定化参照 [Vadala-Roth et al., 2020，DOI 10.1016/j.cma.2020.112978](https://pmc.ncbi.nlm.nih.gov/articles/PMC7263477/) 的式 (21)、(24)–(26)。κ_stab 是数值参数，不是新的物理体积模量。对于理想不可压缩连续解，J=1 时新增体积项消失，球应力由不可压缩压力调整；离散解仍会受到影响，需要验证。

本轮沿用 E=30 kPa、ν=0.3，剪切模量 G=11.53846 kPa；取 κ_stab=53.84615 kPa，对应文献关系中的数值 ν_stab=0.4。原物理输入没有改为 ν=0.4。投影会消除原附加应力的球形成分，包括原 λ 项，因此该选项不能解释为单纯在原体积刚度上再加一份刚度。

配置写在 `solid` 中：

```json
"volumetric_stabilization": {
  "formulation": "deviatoric-logj",
  "bulk_modulus_dyn_cm2": 538461.5384615385
}
```

**省略该配置或设置为 null 才是原方法。** κ_stab=0 仍会保留偏量投影，并不等价于关闭选项。原有默认配置未修改，也没有自动把新的稳定化结果替换为正式基准。

数值切线由原自动微分流程同时对偏量投影和体积项求导。没有增加局部等容约束、强制居中、禁止侧弯或新的流固外迭代。

## 2. 新应力的实现验证

- 新增与相关回归测试共 **19 项通过**，含实际 CUDA 执行。
- 核对偏量 Cauchy 应力不变、体积能量梯度、刚体客观性、合力/合力矩，以及完整有限元切线对有限差分。
- 默认关闭与显式 null 的节点力逐位一致；新旧模型的 `applied_tension` 完全一致。
- 编译后的 GPU 力与可读参考实现一致。
- 新应力另做独立 DOLFINx/UFL 组装：288 节点、768 四面体；节点力相对差 **3.225e-15**，完整切线作用相对差 **9.856e-16**。该项为独立 CPU 有限元组装核对，CUDA 等价性另由前述测试验证；没有将它说成新的完整三场独立轨迹对照。

原已通过的多步三场参考与二维性能实验没有重复。

## 3. 为何采用 60 ms 开关窗口

首次探索用保存的 120 ms 电状态、参考管壁和零流速构成新的初值问题。约 67 kPa 主动张力被瞬间放到未变形管壁上，产生很强的流动冲击：原固体在第 63 步后触及 IB 支撑保护，细固体在第 45 步后触及原 CFL 上限。两组均保留失败状态，没有放宽保护、改时间步或将失败标为完成。

随后改为读取已经连续演化到 60 ms 的接受状态，保留 x、previous_x、流速、压力、电位、GPB/Land 状态及绝对电时钟，只在此刻显式切换附加应力公式，并重算节点力。这样可以复用原 60–100 ms 基线，只运行新增的稳定化分支。

这是一项**模型开关筛选**，不是“从静息始终采用稳定化”的完整轨迹。它能评价该设置是否值得继续，但不能直接替代后者。

两档均使用：

- 管长 2 cm，内半径 0.3 cm，壁厚 0.1 cm；同一物理多面体几何。
- 原固体 3936 节点/15360 四面体，细固体 25920 节点/122880 四面体。
- EP、GPB、Land 始终在原 3936 节点上；使用等长 Land 幅值分支。
- MAC 为 64³，箱体 2.8³ cm³，原点 (−0.7,−0.7,0) cm，h=0.4375 mm；与已完成扩大箱体基线一致。
- EP/FSI 步长均为 50 μs，ODE 为 2 μs；无新刺激、无流体/固体网格再加密。
- 每组推进 800 步，到绝对电时钟 100 ms；原求解容差、保护条件不变。

原基线有每 10 ms 的场文件，新结果有每 2 ms 的场文件。公平比较使用全部共同场时刻 **60、70、80、90、100 ms**，没有用不同输出频率下的极值比较。

## 4. 短程结果

| 指标 | 原固体：基线 → 稳定化 | 细固体：基线 → 稳定化 |
|---|---:|---:|
| 共同采样时刻最大壁体积误差 | 2.5944% → **0.5909%** | 1.0462% → **0.1800%** |
| 体积误差减少 | **77.22%** | **82.79%** |
| 100 ms 局部 J 的参考体积 RMS 偏差 | 0.1010 → 0.08427 | 0.05523 → 0.04763 |
| 100 ms 最小 x-y 投影等效内径 | 2.6413 → 2.7891 mm | 2.5627 → 2.6113 mm |
| 共同节点电位最大差 | 9.24e-14 mV | 9.95e-14 mV |
| 共同节点钙最大差 | 3.11e-15 μM | 5.44e-15 μM |
| 最大输入张力差 | 0 kPa | 0 kPa |

两组都保留了显著收缩，没有通过把管壁锁死来降低体积误差。稳定化后 100 ms 内径分别比原基线大约 5.60% 和 1.89%；这反映离散机械响应发生变化，不能把新旧内径差直接当作相对于真解的误差。

原固体在该窗口的最小 J 为 0.7657、最大 J 为 1.2726；细固体为 0.8181 和 1.2248。因此，**整体壁体积误差很小，并不意味着每个单元都接近严格不可压缩**。局部 J 精度仍是后续检查项。

两组均接受全部 800 步。已采样非线性残差/阈值最大分别为 0.894 和 0.151。图中的内径使用现有 x-y 投影定义；本窗口的中心线横向位移很小，细固体共同采样最大约 0.00323 mm。较晚的大侧弯阶段仍不能把这种投影内径直接当作法向真实内径。

图见 `comparison.png/pdf`：左上为壁体积漂移，右上为局部 J 的 RMS 偏差，左下为投影内径，右下为原 Land 张力输入。实线为稳定化、虚线为复用的原基线。

## 7. 压力字段与文件位置

稳定化启用后，MAC 输出仍是 Eulerian 压力乘子 π。纯流体区域 π 是物理压力；稳定化管壁内的平均物理压力为

    p_wall = π − κ_stab ln(J)/J

因此不能直接拿新旧管壁中的 MAC 压力数值比较物理压力。标准驱动的稳定化输出说明已补充这一点；新短程驱动也明确将其标为压力乘子。输出说明的修改不改变压力方程或边界条件。
