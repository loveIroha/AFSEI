# 微米双层圆管：有效主动载荷验证与性能定位

日期：2026-10-23。已将代码、可选求解器和分析记录放到服务器 AFSEI。本轮测试已结束，没有启动完整周期。

## 结论

电激活产生的 Land 张力可以驱动双层管壁收缩；零主动张力对照不发生运动。但当前 MAC 分辨率下，加载探针的累计固定端容积—通量差为5.29%，定量精度尚未通过，不能当作论文曲线复现或效率基准。

此验证先在固定几何上将电状态推进到40 ms，得到约1.219 kPa张力，再独立推进0.25 ms三场。两个时钟分别记录。探针采用4步、共0.2 ms的加载过渡，避免瞬时释放；它不属于正式算例的 Land 载荷，也不是完整生理过程的续算。

## 容积—通量预算

固定端控制体容积变化为 −5.35837×10⁻⁹ mL；逐步累计净入流为 −5.64179×10⁻⁹ mL；差值为 +2.83411×10⁻¹⁰ mL，占该控制体容积减少量的5.289%。几何恒等式误差不超过4.60×10⁻²³ mL。孔面与储液区通量闭合仍成立，但不能消除材料壁面与 Eulerian 流体的空间传递差异。

只对保存的末步做CPU积分细分，没有推进任何方程。每个壁面三角形细分为1024个子三角形后，该步差异分解约为：

| 项目 | mL/s |
|---|---:|
| 固定端控制体该步差异 | +2.86007×10⁻⁷ |
| 旧几何上的材料壁面速度通量 − RT0流体通量 | +2.82926×10⁻⁷ |
| 几何时间更新项 | +5.29899×10⁻⁹ |
| 虚拟连接面相对通量 | +1.68030×10⁻⁹ |
| 散度/表面积分剩余项 | −3.89816×10⁻⁹ |

因此，在这个末步中，时间几何更新项约占差异1.85%，诊断积分剩余项幅度约占1.36%，主项是旧几何上的材料壁面与RT0重构流体通量之差。这支持优先检查空间传递与边界分辨率；RT0不是原IB正则化插值，因此这些数值不能命名为原非线性方程残差，也不能直接当作已证明的真实壁面漏流率。

将壁面分成两端各15 μm及内部150 μm：两端合计占管长16.7%，贡献末步约60%的上述空间差异，内部仍占约40%。这是优先核对端口/接头/IB附近离散的线索，并未证明某一项代码有错误。当前有效开口面积1.58203×10⁻⁵ cm²，比解析πr²小约19.4%；心肌厚度仅约1.24个MAC间距。二者都说明目前网格不能作为已收敛的定量基准。

## 性能工作

没有改动NS、EP、GPB/Land、本构、MAC空间算子、压力多重网格、FE/IB或BE–BE时间推进；正式Land载荷未加探针的释放过渡。没有新增流固外循环。

新增可选黏性线性求解器 `BEViscousPCG`，解的仍是同一方程H u=b，H=I−dt·μ/ρ·L。外部法向MAC半控制体权重通过平方根变换使算子在Euclidean内积下对称；三个速度分量合并为块对角PCG，并按原各分量残差目标归一化。返回后仍逐分量检查原物理真实残差。压力投影和IB保持原样，默认旧配置继续用Jacobi。

6项CPU/CUDA数值检查、17项原封接/RC检查和1项配置检查通过。制造解使用残差对应的L2误差界，不用近零节点的点相对误差代替求解精度。

同网格、同载荷、同残差目标下，暖机后完整一次流体求解（包含压力投影）中位耗时：

| 求解器 | 秒 |
|---|---:|
| 原Jacobi | 0.36241 |
| 同矩阵PCG | 0.27524 |

加速约1.317倍，速度场相对L2差5.84×10⁻¹²。不是EP耗时对照，也不是完整三场或周期的加速比。

受载三场探针中，原Jacobi前两步分别约170.35、170.14秒；PCG后续三步约125.28、116.24、129.50秒。载荷阶段不同，不据此计算严格三场加速比。5步共1580次GMRES迭代、1916次流体求解；后续PCG步仍有每步约300次GMRES迭代及数百次流体响应调用。零主动张力对照暖机后约0.26–0.30秒/步。

这些调用来自原有Newton/GMRES接口响应计算，没有新增强耦合外循环。当前新微米模型的主要成本是受载隐式求解，不是EP直接运算。上述探针含加载过渡，不能外推真实左心室或完整圆管周期耗时。
