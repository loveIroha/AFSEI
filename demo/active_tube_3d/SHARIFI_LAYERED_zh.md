# Sharifi 微米双层心管：电激活扩展算例

本配置用于将几何与基本物性从厘米单层示例推进到论文尺度。它尚不是论文曲线的定量复现，也不是已建立的计算加速基准。旧 `tube_sharifi_rc_gpu.json`、二维平面通道及既有结果保留。

论文：Sharifi et al. (2021), *Valveless pumping behavior of the simulated embryonic heart tube as a function of contractile patterns and myocardial stiffness*, DOI 10.1007/s10237-021-01489-7；依据 §3、图1、表1、公式(1)–(5)。

## 配置与代码

- `configs/tube_sharifi_micron_layered_gpu.json`：500 ms 单次刺激窗口，尚未完成整段验证。
- `configs/tube_sharifi_micron_layered_check_gpu.json`：0.1 ms / 2步接入检查，不代表收缩周期验证。
- 主要求解入口仍为 `demo/active_tube_3d/run.py`，调用已有 `BEIBStepper`、MAC 多重网格/压力投影与积分点 FE/IB。
- 新增 `ep/layered_circular_tube.py`，使用原 P1 力、切线及边界力装配接口。双层弹性连接为共享节点，不增加接触或多孔介质。

## 物理量对照

| 项目 | 论文 | 新配置 |
|---|---|---|
| 管长 | 180 μm | 0.018 cm |
| 管腔直径 | 50 μm | 0.005 cm |
| 胶质厚度 | 12 μm | 0.0012 cm |
| 心肌厚度 | 3.5 μm | 0.00035 cm |
| 血液密度 | 1035 kg/m³ | 1.035 g/cm³ |
| 血液黏度 | 0.008 Pa·s | 0.08 dyn·s/cm² |
| 心肌 Neo-Hookean 常数 | 10 kPa 或 60 Pa | 本配置选择 10 kPa，即 μ=100000 dyn/cm² |
| 胶质常数 | 表1为4 Pa，正文为5 Pa | 明确选择表1：μ=40 dyn/cm² |
| 泊松比 | 0.49 | 两层均0.49 |
| 入口 | 实际管口零压 | 隔离入口储液区外端面零压 |
| 出口 | 实际管口两元 RC | 隔离出口储液区外端面两元 RC |
| R | 60 mmHg·s/mm³ | 原值，换算60000 mmHg·s/mL |
| C | 0.26 mm³/mmHg | 原值，换算0.00026 mL/mmHg |
| 固体端部 | 固定 | 有限全向参考面弹簧，近似固定；非严格 Dirichlet |
| 驱动 | 规定的时空压缩力，作用在心肌外侧 | EP–GPB–Land 内部环向主动 PK1 应力 |

材料常数 μ 不能当成 Young 模量。ν=0.49 时，心肌 E=2μ(1+ν)=29.8 kPa，胶质 E=11.92 Pa。现有本构保留有限可压缩的 log(J) Neo-Hookean 扩展；论文公式(1)未明确给出完整体积项，因此不能宣称有限可压缩本构已严格相同。P1近不可压缩材料还需要检查锁定和网格收敛。

## 离散与激活范围

本配置轴向24段、周向32段，胶质径向3段、心肌径向2段，共4800个力学节点、23040个四面体；初始圆截面是32边形，容积比解析圆柱约小0.641%。EP仅在心肌层运行，含界面节点，共2400个EP节点、9216个四面体。胶质内部没有电位、GPB或Land自由度，胶质单元主动应力为零。心肌/胶质界面只要求力学位移连续，电问题在心肌边界绝缘。

流体继续使用64×64×96规则MAC网格；外盒180×180×270 μm，管两端各留45 μm储液区。网格间距2.8125 μm；心肌厚度仅约1.24个MAC间距，且IB核有有限宽度，因此当前仅是接入网格，不能当作已收敛的薄层流固结果。固定隔板、接头、管外虚域流体和参考压力通气仍保留，都会使边界与论文ALE管腔模型存在差异。

EP用原nodal FEM＋CN＋轻量Jacobi-PCG，GPB/Land沿用当前参数。电导率保持原电激活示例值，未用论文的机械收缩波速冒充电传播速度；人体GPB也不是斑马鱼胚胎细胞模型。500 ms窗口对应论文120 bpm的周期长度，但当前只施加一次刺激，尚未建立周期稳态。

微米尺度下的局部电刺激必须单独验证。原35.714 μA/cm²、2 ms刺激仅覆盖离散心肌体积的6.25%；电扩散很快，体积平均电流只有2.232 μA/cm²，实测2 ms没有节点越过−20 mV。新配置将局部刺激设为571.429 μA/cm²，使体积平均电流为35.714 μA/cm²，不改变GPB、Land、电导率或脉冲持续时间。EP单独运行4 ms时全部心肌节点曾越过−20 mV，峰值68.94 mV、末态约39.75–39.79 mV，状态有限。该剂量是电激活扩展的明确选择，不来自论文；仅验证了触发，不能当作完整动作电位或论文收缩波形的验证。

可单独检查激活，不推进流固：

```bash
python demo/active_tube_3d/check_layered_ep.py \
  --config demo/active_tube_3d/configs/tube_sharifi_micron_layered_gpu.json \
  --duration-ms 4 --output results/my_layered_ep_check
```

流固仍为BE–BE，空间传递仍为原Griffith–Luo统一积分点FE/IB。新配置因长度和体积缩小，分别收紧EP、质量矩阵及位移求解的绝对容差；隐式黏性Jacobi的最大迭代预算提高，以适应dt·ν/h²增大。未通过放松残差、改变PDE或增加流固外循环获得通过。

## 当前复现程度

可以称为“主要几何及材料/流体/RC参数对齐的电激活扩展模型”。不能称为“Sharifi定量复现”：严格固支、实际管口压力条件、外侧规定载荷及其时空波形、完整收缩—舒张、流量/压力/形变曲线误差和网格收敛尚未完成。

保留EP–GPB–Land是本项目的扩展方向；若用于证明数值方法效率，应另有共同规定载荷、相同物理条件和误差目标的FSI基准。论文为轴对称ALE，当前为完整三维MAC＋IB，直接比较整机耗时不能证明算法更快。
