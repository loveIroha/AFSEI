# GPB / 原始 ORd：统一外部条件的传播对照

本轮在 RTX 4090 上完成固定组织的细胞模型对照，复用 AFSEI 的 nodal P1
FEM、PyTorch 装配和 AmgX PCG-AMG。GPB 使用现有源项目变体；新增的原始
ORd 2011 仅作为可选细胞模型接入固定组织 demo。真实 LV 三场驱动继续使用 GPB，
固体、流体、Land、本构与循环模型均未在本实验中推进。

## 对照合同

同一协议中的两次计算只改变 `cell_model`。公共分析接口要求配置中的区域、
纤维、组织电参数、刺激、边界、时间步、初值准备策略、观测判据完全一致，
还逐项比较实际节点、单元和刺激掩码。报告保存公共条件及其 SHA256。
输出频率和显示名称不作为物理条件。

不同 h 使用同一个闭区间刺激盒，但顶点积分的离散刺激体积会随 h 改变；
每次报告都保存 `stimulus_nodal_quadrature_volume_cm3`。同一模型对中的离散源
完全相同，跨网格到达时间变化则同时含波前分辨率及刺激边缘积分变化。

| 外部条件 | 三维主实验 |
|---|---|
| 区域 | `[0,2] × [0,0.7] × [0,0.3] cm`，固定三维组织 |
| 网格 | 每砖块 6 个相容 Freudenthal 四面体；h = 0.5 / 0.25 / 0.125 mm |
| 方向 | f=x，s=y，n=z |
| 膜电容、面积体积比 | Cm=1 µF/cm²，Sv=0.1 /cm |
| 参考扩散系数 | D=(1.171, 1.171/3, 1.171/3) cm²/s |
| 对应电导 | g=(0.1171,0.03903333333333334,0.03903333333333334) µS/cm |
| 刺激区域 | `[0,0.15]³ cm` 的节点，空间闭区间 |
| 刺激 | 35.714285714285715 µA/cm²；时间 `[0,2) ms`，单次脉冲 |
| 边界 | 所有外表面电流零法向通量 |
| 初值准备 | 各模型原生静息状态，均经过 200 ms 无刺激孤立细胞准备 |
| 时间窗 | 准备结束后重新计时，组织观察 120 ms |
| 时间步 | EP 0.05 ms，ODE 0.002 ms；时间细化对照为 0.01 / 0.001 ms |
| 数值精度 | FP64，AmgX PCG-AMG，rtol=1e-10，atol=1e-13 |
| 激动时间 | 首次向上跨越 0 mV，相邻 EP 状态间线性插值 |
| 观测 | 探针、x 方向边线、体对角线、完整三维场；图中的二维面只是显示切片 |

“统一初值准备”不意味着将不同模型的离子浓度和门变量强行设成相同数值。
它们是模型内部状态；本轮保留各自原生状态并使用相同准备时间和算法。
200 ms 无刺激准备也不等于周期起搏后的稳态。主步长准备后的 Vm 为
GPB −81.55550 mV、ORd −87.96928 mV；胞质 Ca 分别为 0.105951、0.075458 µM。
实际值记录于各报告的 `initialization` 或最初探针行。

每次 EP 步固定左端 Vm 推进其余离子状态，使用现有 GPB 的两阶段 SDIRK
及相同固定点停止规则，随后在隐式单域更新中使用平均离子电流和公共刺激。
ORd 也采用同样流程；没有更换 PDE、AMG 参数或给 ORd 单独调整刺激。

## 实际三维结果

`远端` 指体对角角点 `(2,0.7,0.3) cm`；下面是从脉冲开始计时的到达时间，
不是从首个激动节点计时的传播历时。未到达记为“未到达”，不以最后局部激动
或观察窗 120 ms 替代。激动比例是整个三维网格中满足公共 0 mV 判据的节点比例。

| 协议 | GPB 远端 / ms | GPB 激动比例 | ORd 远端 / ms | ORd 激动比例 |
|---|---:|---:|---:|---:|
| 参考 D，h=0.5 mm | 39.9083 | 100% | 未到达 | 1.9048% |
| 参考 D，h=0.25 mm | 33.7067 | 100% | 未到达 | 2.9734% |
| 参考 D，h=0.125 mm | 32.0861 | 100% | 74.3563 | 82.0442% |
| 参考 D，h=0.25 mm，EP/ODE=0.01/0.001 ms | 33.1939 | 100% | 未到达 | 4.2768% |
| Table 1 字面换算 D=(11.7,3.9,3.9)，h=0.25 mm | 11.5294 | 100% | 未到达 | 0% |

这些协议共 10 次组织模拟，均完成到 120 ms，并通过主求解器的状态及真实
方程残差验收。完成求解不代表传播或网格收敛通过。

GPB 从 h=0.25 到 0.125 mm 的远端时间减少约 4.81%，0.25 mm 时间细化减少约
1.52%。原始 ORd 在两种较粗网格上局部激动但未完成传播；细化到 0.125 mm
恢复远端到达，同时还有约 18% 节点未跨越判据。它的体对角线 LAT 非单调，
不支持把该结果当成均匀、收敛的直线传播。时间细化没有解决粗网格未到达。

0.125 mm 时，扣除首个角点激动后的传播历时为 GPB 30.9679 ms、ORd 72.7107 ms，
比值 2.34794；**这只是本次尚未收敛三维实验的比值，不是两个模型的普适速度比。**

## 与 Santiago Figure 6 的关系

原始 demo 按 Santiago Table 1 的 `g`、`Sv` 字面单位组合使用 Df=11.7 cm²/s。
本轮另外使用参考组织比较中的 Df=1.171 cm²/s，明确分成两个协议，
不推断哪一个就是作者实际代码参数，也不通过改刺激来使曲线贴合论文。
上述 Df=1.171 并非“全部 Santiago 参数已核实一致”的复现。

同一 0.25 mm GPB 模型的到达时间从 11.5294 增至 33.7067 ms，因此此前较快
到达不能全部归因于换成 GPB。相应传播历时变化约 3.19 倍，接近扩散系数
十倍差异对应的平方根尺度。这支持组织扩散尺度是之前比较中的重要混杂因素。

论文图示 0.5 mm 远端约 55–60 ms、0.25 mm 约 46–47 ms、0.125 mm 约 38–39 ms，
这里只是读图量级，不是原始数据或精确数字化结果。图中观测线是否严格为体对角线、
作者使用的确切刺激、步长、激动判据和组织参数口径仍需进一步核实。
原文说明大部分细胞常数未变，但没有列出完整细胞参数；也尚未确认其组织
实现是否保留原始钠电流。因此此处的原始 ORd 移植不能视为 Santiago 代码副本。
所以本轮完成的是**受控模型对照，而非已经复现 Santiago 的收敛曲线**。

## 平面波控制

另设固定 `[0,2] × [0,0.1] × [0,0.1] cm` 的窄组织，刺激覆盖
`x∈[0,0.15] cm` 的整个截面。两模型仍使用同一 D、准备策略、刺激幅值与时长、
0 mV 判据、EP/ODE=0.01/0.001 ms。沿 x 的间距为 0.0625 / 0.03125 mm，
每个横截面方向保留一个砖块，沿用同一个三维四面体 FEM 与 AMG 求解器。
单元检验确认其内部纵向二次场作用给出 −2gf 的精确结果。
传导速度取 x=0.5 与 1.5 cm 探针间的 1 cm / 激动时差，排除刺激区和端部影响。
这是独立几何的空间分辨率控制，不能替代三维角部刺激的完整网格收敛。

| 纵向 h / mm | GPB CV / cm/s | 原始 ORd CV / cm/s | 全域激动 |
|---|---:|---:|---|
| 0.0625 | 73.42362 | 41.11377 | 两模型均 100% |
| 0.03125 | 73.87882 | 41.50167 | 两模型均 100% |

网格减半后的速度变化为 GPB +0.620%、ORd +0.943%；在固定公共时间步下，
这一纵向空间细化的速度变化已经小于 1%。细网格上的 GPB / ORd 速度比约
1.78014，支持原始 ORd 比当前 GPB 慢这一模型差异。该结果不能推出三维角部
刺激已经收敛，也不能归结三维未到达仅有一个原因；波前空间分辨率、刺激区
向周围组织供电的源汇关系，以及初始准备/积分设置都会影响传播是否成功。

实测 GPB / ORd 比文献 71.4 / 37.8 cm/s 高约 3.5% / 9.8%。由于没有复制文献
周期起搏稳态、GPB 精确版本及全部离散设置，这不是对文献数值的严格误差检验。
本轮总共完成 10 次三维模拟和 4 次平面波控制；精简数值记录随代码保存于
`reference_data/cell_comparison_20261013.json`。

## ORd 实现与验证

使用 original ORd 2011 的原始钠电流（GNa=75），不使用 TP 钠电流替代或额外电导缩放。
来源为 Physiome 的原始方程编码，版本
`2593df010620dde185c41853d6264c30b12c4aa1`，40 个离子 ODE 加 Vm。
参考 C 的 SHA256 为
`f6f2e979416149117029043af9718c7fefb590f0b1b05720c2d13847ae9cff92`。
来源、散列、原生初值和修改项随包保存于 `ep/ord_provenance.json`；
`scripts/generate_ord_reference.py` 可再生成 CUDA 方程头并校验来源内容。

两处适配是：关闭原方程内部刺激以使用公共组织刺激；为 0 mV 的 GHK 可去奇点
使用解析极限。没有静默裁剪或替换非有限状态。CUDA RHS、原生初值、SDIRK 子步
及平均电流与独立编译的原始 CPU C 比较通过；0 mV 极限另行验算。
配置/几何/观测检查同时覆盖模型外部条件合同、P1 对角插值及窄组织离散算子。
这些检查证明方程移植与调用行为，不等价于所有组织传播条件已验证。

文献 Elshrif & Cherry (2014) 在其统一条件下报道 GPB/原始 ORd 速度约为
71.4 / 37.8 cm/s，可作为方向性参考；其起搏准备、GPB 状态数及空间时间离散
与本实验不完全相同，不能直接要求数值相等。

```bash
cd /mnt/large2/gjh/AFSEI
source scripts/activate_afsei.sh

# 标准 JSON 定义的 10 个三维对照，输出目录必须新建。
```
