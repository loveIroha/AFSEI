# MAC 基底封面、端口流量与压力功算子

本阶段实现原 MAC 框架的运动基底封面、理想化 MV/AV 区域、相对流量积分，
及与流量配对的压力载荷算子。它们是物理密封与循环接口的前置工作。
本阶段尚未向时间推进残差加入密封、单向阀或 RCR。
运行检查仅读取已有 MAC 状态，原 8 mmHg 规定内膜载荷继续保留在主线。

流体依然是原 128³、13 cm 外箱的交错规则 MAC 网格。
基底的三角形是二维边界积分面，不是拟合血液域的四面体流体网格。
没有调用已有四面体血液网格生成器，也没有改动原 MAC 隐式求解器。

## 几何与运动

从参考心肌内膜的唯一开口边缘建立平均中心三角扇。
真实 LV 边缘有 77 个节点，参考平面误差 5.85e-8 cm。
理想化端口沿用此前设置：参考基底局部 MV 中心 (0.65,0) cm、半径 0.55 cm；
AV 中心 (-0.65,0) cm、半径 0.40 cm。没有解剖瓣膜。

两端口必须不相交、严格位于参考边缘内部。
每个扇形三角面作 4 级细分，用子三角形重心划分非端口、MV、AV 三个区域。
圆边界采用分片近似，并检查区域面积误差；默认容许 3%，过粗会报错。
真实网格共有 19712 个边界积分点，MV/AV 参考面积误差分别 +0.591% / −0.205%。
参考 MV/AV 近似面积为 0.955945 / 0.501626 cm²。

积分点按扇面上的材料重心坐标随当前边缘和平均中心运动。
基底不会被压回平面，也不会被吸附到 MAC 格点上。
预加载后实际基底已有约 0.01764 cm 的翘曲，端口面积随预加载变成
1.62865 / 0.84319 cm²；刺激后 20 ms 为 1.58284 / 0.81614 cm²。
这是一种随材料运动的理想化开口定义，不等同于真实瓣口测量。

## 离散算子与符号

对每个交错速度分量使用与原 MAC IB 传递相同的四点 Peskin 核。
每个积分点必须有完整支撑并远离外箱法向边界；不裁剪或归一化权重。
面积向量取从腔内指向腔外的方向，区域顺序为非端口、MV、AV。

将积分权重与插值核合并、按规则网格速度自由度合并重复条目，得到三行稀疏算子 B。
这三行用于区域净流量与端口压力功；仅令非端口净流量为零不能保证局部不透流。
绝对流量是 `B u`。材料封面运动对应算子 C，材料流量是 `C w`。
相对流量 `Q = B u − C w`，因此 `Qin_MV=−Q_MV`、`Qout_AV=Q_AV`。
单位为 cm³/s，即 ml/s；压力传入算子前由 mmHg 转为 dyn/cm²。

压力流体力密度取 `f=−Bᵀp/h³`，只有一次面积权重。
由于所有支撑都在外箱内部，相关速度控制体体积为完整 h³，
满足 `Σ h³ u·f = −p·(B u)`。
同时构造材料虚功反力 `r=Cᵀp`，含平均中心运动对所有边缘节点的贡献，
使 `Σ h³ u·f + w·r = −p·Q`。

材料反力目前只用于检查这个代数关系，并未作为新增心肌载荷施加。
将来要选择运动端口/封面的约束模型、明确反力如何传递，再连接该项。
它不是凭空增加的解剖瓣膜力，也不代表主线已经承受 RCR 压力。

## CPU/GPU 与真实 LV 验证

8 项 CPU/GPU 检查通过：仿射速度再现、区域面积分割、翘曲封面、
封闭材料面的体积导数、绝对和相对压力功配对、力传递及非法支撑/欠分辨拒绝。
加上原 MAC 参数保持和实际步进检查，共 10 项通过。
另外在真实 LV 的 8 mmHg 源预加载、刺激后 10 ms、20 ms 三个检查点执行 GPU 检查。
输入检查点哈希在检查前后核对，物理状态不推进。
压力功检查使用 (0,8,85) mmHg 的测试向量，不将它施加到已有物理状态。

| 状态 | 非端口基底相对泄流 ml/s | 采样 MV 流入 ml/s | 采样 AV 流出 ml/s | 心肌腔体体积导数 ml/s |
|---|---:|---:|---:|---:|
| 预加载后，刺激前 | 0 | 0 | 0 | 0 |
| 刺激后 10 ms | 44.464 | −3.056 | 1.579 | −49.091 |
| 刺激后 20 ms | 334.758 | −23.731 | 11.816 | −369.603 |

这些是当前未施加密封与单向阀的 MAC 状态上的采样值，**不是生理瓣口解**。
MV 采样流入为负，表示血流通过理想化 MV 区域向外流动。
第 20 ms 仅使用 MV/AV 时，`dV/dt−(Qin−Qout)=−334.056 ml/s`，
其中大部分来自未封闭的非端口基底；不能忽略它并将 AV 流量直接送入 RCR。

把所有基底区域计入后，第 20 ms 仍有 0.7021 ml/s 的流量缺口。
同状态采样的内膜相对通量为 0.2574 ml/s，闭合表面的流体绝对通量为 0.9595 ml/s。
两者满足上述缺口的分解关系。
这里的 Peskin 表面采样、弱形式 IB 无滑移、有限表面积分
并不构成 MAC 压力投影的精确离散 Gauss 公式。
这些剩余误差需要在后续密封及接口守恒工作中检查；不能用小的网格散度代替腔体质量检查。

几何上，完整内膜加运动封面的材料通量与 `DV(x)·w` 的差值
最大 5.68e-14 ml/s。最终复核中压力相对功关系误差最大 7.30e-17（相对量）。
实际体积的两时刻差分与当前几何导数相差 0.0333 ml/s，
属于本次步长下不同几何时间离散量的差别，报告分别列出两者。

## 耗时与输出

RTX 4090，以上 20 ms 状态，10 次同步 GPU 测量均值：

| 运算 | 耗时 |
|---|---:|
| 更新封面并建立合并后的流量算子 | 4.55 ms |
| 相对流量积分 | 0.284 ms |
| 生成压力力密度 | 0.229 ms |
| 生成材料虚功反力 | 0.207 ms |

四项合计约 5.27 ms，约为上一阶段 1.35 s 主步进耗时的 0.4%。
这是边界算子的独立成本，尚不包含未来密封约束和 RCR 联立求解。
主步进代码未增加这些调用；其实际耦合后性能仍需重新测量。

服务器验证输出：`results/phase12_mac128_ports_verified_v2/report.json`。
三个状态各有 `snapshot_0/1/2/basal_ports.vtu`，可在 ParaView 中以
`port_region` 查看非端口=0、MV=1、AV=2 的当前边界。

```bash
python scripts/check_afsei_mac_ports.py \
  --checkpoint results/phase11_mac128_preloaded_20ms_v1/checkpoint.npz \
  --write-vtk --output results/my_mac_ports_check
```

## 下一步

先接入非端口基底的密封条件，再处理关闭瓣口约束和流量驱动压力关系。
约束自由度要与 MAC 分辨率匹配，边界积分点的加密不应等同于增加大量独立约束，
避免过密的点约束产生秩亏或大量重复流体求解。
需要把边界约束纳入原隐式残差及其线性化，验证两阀关闭的体积/泄流和功关系。
随后以实际流量连接 RCR、替换规定 8 mmHg 载荷、建立相容初态，
最后用真实 AV 关闭事件触发源 80 ms 快速张力卸载。
