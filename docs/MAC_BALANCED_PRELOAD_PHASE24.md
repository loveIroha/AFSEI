# 第二十四阶段：功配对压力模态与重新加载的闭合基底静态状态

本阶段实现独立的压力模态传递、显式基底压力反力加载、源 Land 应变历史重算及联立静态验证。
沿用原规则 MAC 网格和 BE–BE 流固框架；这是一条隔离的验证分支，普通周期驱动尚未启用。
源心肌 PK1、材料/纤维参数、GPB/Land 张力和 80 ms 空间卸载实现保持原配置。

## 为什么重新加载

第二十三阶段表明，节点力平衡不自动构成离散 MAC 静压平衡。
此外，闭合流体基底压力对应配对材料反力，旧源预加载只有内膜规定压力，不能直接接替。

新静态加载从原参考几何开始，在每个压力端点求解：

```
F_source_passive+basal(x)
  + F_source_endo(x, P)
  + C_cap(x)^T (P*C_mmhg) = 0
```

`F_source_endo` 继续使用源程序的内膜 follower 载荷；
基底项单独组装，等于实际运动平均边缘盖面流量的材料伴随反力。
没有把源内膜压力载荷静默替换为整腔体积梯度。
均匀压力情况下，两项合计等于闭合体积梯度，仅用于核对反力一致性。
显式盖面不是解剖瓣膜，也不是贴体血液体积网格。

加载每个已收敛的 100×5 ms 名义端点，按源 `SourceLoadingHistory` 计算伸长和 Zs/Zw。
数值续接的中间点不推进历史时钟；EP/GPB/Land 门控保持冻结。
旧预加载几何与旧 Zs/Zw 不导入新路径，原参考材料方向保留。
保存的起始时钟仍为 0.5 s，EP 绝对 tick 为 10000（0.05 ms），
FSI 步号为 0；丢弃的静态试算不推进 EP、Land 或循环时钟。

## 压力模态传递及其伴随

原传递为节点力到 MAC 密度 `S` 和功伴随速度采样 `J=S^T W`。
只对一个已知均匀壁面压力模态作显式离散修正：

```
t = -F_source_endo(x_old,1mmHg)
a = t/(t:t)
T = S + b a^T
I = J + a b^T W
```

单位静压的边界密度来自第二十三阶段的闭合 BS4–BS3 表面压力积分。
用原零 Dirichlet MAC Hodge 算子取得单位势 q，并将理想紧支撑范围
（内膜包围盒外扩两格）之外的积分谐波尾截去；最大截去量独立报告。
不按预加载残余力拟合，不按最终均压归一化，也不给求出的压力加常数。

为与当前 BE 分裂一致，令 `H=I-nu*dt*L_velocity`：

```
phi = q + nu*dt*A_D*q
g = G_D phi = H G_D q     # q远离外箱，边界交换误差为零
b = g + W^-1 B_cap^T (1mmHg) - S t
```

因此一个完整单位闭合压力模态满足：

```
T t - W^-1 B_cap^T (1mmHg) = H G_D q
original_BE_response(H G_D q) = (u=0,p=q)
```

修正及其速度伴随同时施加。与 a 正交的节点力方向继续使用原 S。
这不是源材料或主动力的新模型，是一个实验性的全局压力模态离散修正，
需要进一步空间与动态验证；它不代表完整复现复合 B 样条 IFED 方法。
总力、力矩和刚体速度一致性必须通过实际 GPU 测试，否则拒绝静态状态。

## 避免大压力响应相消

实现采用数学等价的稳定形式：

```
alpha = a:F
T F = S(F-alpha*t) + alpha*(g+cap_unit_lift)
I u = J u + a*((g+cap_unit_lift,u)_W - (t,J u))
T F - cap_lift(lambda)
  = S(F-alpha*t) + cap_lift(alpha*1mmHg-lambda) + alpha*g
```

原 BE 方程是线性的，已知 `alpha*g` 的响应严格为 `u=0,p=alpha*q`。
因此仅对余项调用原 BE 求解，再叠加该压力响应；不会给每次残差或 JVP 增加一个压力求解。
完整密度仍保留供受力/功核对，并测试这种计算与原方程直接完整求解在容差内一致。
压力叠加对应同时存在的真实离散载荷项，不能解释为自由压力规范平移。
`H` 含当前时间步长，因此这是针对现有分裂离散的平衡修正；
静态一致性不能替代它的时间步、空间或动态收敛检查。

## 同一 Newton 中求解心肌位移和基底反力

去除全部规定内膜压力及切线后，未知量是 `dy` 与 `lambda_cap`：

```
F = F_source_passive+basal(x_old+dy) + C_cap_old^T lambda_cap
(u,p) = original_BE_response(u_depart, T_old F - cap_lift(lambda_cap))
dy - dt*I_old u = 0
B_cap_old u - C_cap_old I_old u = 0
```

后一式利用前一运动方程，是原 `dt*B u-C dy=0` 的等价行变换。
静态残差用法向速度单位 cm/s，避免很小 dt 将压力功误差隐藏在位移残差中。
对盖面残差再施加可逆行缩放 `M=I+15*w*w^T`，其中 `w=area/||area||`。
均匀压力功对应面积加权的平均法向通量，该方向被缩放 16 倍以提高求解精度；
其余方向保持原缩放，零残差仍是同一组约束，没有增加约束或未知量。
JVP 使用同一个 M，预条件器显式使用 `M^-1=I-(15/16)*w*w^T`。
仍独立检查实际 `(x_new-x_old)/dt` 的盖面相对流量，不能只检查投影速度。
解析材料切线和缓存的基底预条件器继续使用；预条件器按新残差单位转换。
没有外层完整 FSI 反复求解，没有额外规定腔压未知量或人为压力偏移。

独立静态试算提高非线性精度，原正式运行配置与验收目标不变。
连续试算检查原 1e-9 cm 位移、1e-6 cm/s 流速、0.05 mmHg 均压误差、
1e-3 ml 体积变化、1e-5 ml/s 盖面通量及 1e-7 功误差目标。
实际压力由材料力和求出的基底反力决定，没有预先把场设成 8 mmHg。
真实 128³ 网格的联合残差在约 1.3e-11 处出现浮点停滞，
因此试算使用 `atol=3e-11`、`rtol=1e-12`，并保留上面全部独立物理目标。
这两个数只控制隔离静态试算，不修改既有生产步容差。

## 运行与结果格式

```bash
python scripts/initialize_afsei_mac_balanced.py \
  --checkpoint results/phase10_mac128_source_preload_v1/checkpoint.npz \
  --pressure-mmhg 8 --trials 3 --level 2 \
  --output results/my_mac_balanced_preload

python -m pytest -q --show-capture=no \
  tests/test_afsei_*.py tests/test_ep_*.py tests/test_mac_spectral_dirichlet.py
```

输入仅提供参考网格与配置；输入校验值前后核对。
完成静态加载后先写 `loading_history.json` 和独立的 `loading_result.npz`，
再开始联立验证。后者仅保存这条新路径的几何、参考字段和应变历史，
不是静态交接验收结果，也不是 EP/FSI 续算检查点。
验证失败会写失败 `report.json` 并保留加载状态，便于定位或重复积分精度检查。
只有全部静态验收通过才写 `preload_result.npz`。
后者有独立生产者 `afsei-mac-pressure-mode-preload-result`、数组/元数据校验和与完整参考网格、
初始 EP/GPB/Land、重算的应变历史、材料力、MAC 压力和基底压力。
它是可审查的静态预加载结果，**普通 `run_afsei.py --resume` 会拒绝该格式**。
不能把尚未启用的新传递和历史状态当成旧周期检查点续算。

可在同一新加载路径上提高表面积分层级，避免重新运行 100 个加载端点：

```bash
python scripts/initialize_afsei_mac_balanced.py \
  --checkpoint results/phase10_mac128_source_preload_v1/checkpoint.npz \
  --reuse-balanced-result results/my_mac_balanced_preload/loading_result.npz \
  --level 3 --trials 3 --output results/my_mac_balanced_preload_refined
```

复用会核对数组校验和、完整参考网格、当前被动/基底力平衡、最终伸长、
100 个物理加载端点及 Zs/Zw。它拒绝旧纯固体预加载格式。
完整验收结果的 `preload_result.npz` 也可用于此检查；不会自动启用周期驱动。
