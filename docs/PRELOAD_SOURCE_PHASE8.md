# 第八阶段：源纯固体预加载核对及 Land 加载历史

本阶段完成两项源模型对齐：独立验证纯固体的 8 mmHg 被动平衡；将预加载期间的机械伸长与 `Zs/Zw` 历史带入三场首次刺激。没有调整源材料来匹配指定充盈体积，也没有把纯固体的压力边界直接叠加到流固载荷上。

## 源加载期间实际更新什么

核对固定提交 `5bdde73c6be10cefadb005a0fcec5fdb6521f336` 的 `main.cpp`、`ep_cycle_gate.h`、Land 历史更新及 UFL：

- 默认预加载为 0–500 ms，压力从 0 线性上升到 8 mmHg，机械步长 5 ms。
- 电位、GPB 和 Land 门控状态在首次刺激前冻结。
- 每个已接受的机械步仍投影纤维伸长，更新 Land 的应变历史；加载期间主动应力为零。
- 首次刺激沿用加载末端的伸长、`Zs` 和 `Zw`，不会把它们重新置零。

因此第七阶段的实际缺口是机械加载历史。此前“源加载期需要重放 EP/ODE 静息演化”的推测不成立，相关文档已纠正。

`SourceLoadingHistory` 用一致 CG1 质量矩阵投影单元纤维伸长，初始伸长为 1，`Zs=Zw=0`。每 5 ms 更新

\[
Z^{n+1}=e^{-c\Delta t}Z^n+
10(\lambda^{n+1}-\lambda^n)\frac{1-e^{-c\Delta t}}{c\Delta t},
\qquad c_s=40.14\;s^{-1},\quad c_w=405.86\;s^{-1}.
\]

数值压力续接失败时可以减小增量，但额外的续接中间点不代表新的物理加载步。只有 100 个规定压力端点更新上述历史。完整历史写入三场检查点和首次主动载荷的旧状态；保存、重启后继续使用它。实现对齐源默认 100×5 ms 方案；若原程序启用物理时间步回退，其具体接受时间序列还需另行匹配。

## 两种压力平衡为什么不同

原纯固体 UFL 只在内膜 `ds(2)` 上施加随形压力：

\[
F_{\mathrm{passive}}+F_{\mathrm{basal}}+
F_{\mathrm{endo}}(x,p)=0.
\]

原程序通过移动的基底扇形盖面计算闭合腔体积，但不在该盖面施加压力。原内膜压力的随形切线必须按开口表面求导，不能直接用闭合体积 Hessian 替代。

AFSEI 双阀关闭时，实际血液压力作用于闭合腔体。相容的初始化是

\[
F_{\mathrm{passive}}+F_{\mathrm{basal}}+
p\nabla_x V(Hx)=0.
\]

其中 `H.T` 把包括基底封口在内的血液反力回传到心肌。两种平衡的差别是封口压力及其经运动映射返回的反力。三场推进继续只接受一份血液界面反力。仅内膜压力的平衡结果用于对照，不能生成三场完成检查点。

## 独立参考核对

新增 `check_afsei_preload_alignment.py` 单独求源内膜压力的平衡，并把源与闭合界面两组变形输入独立 FEniCS：

1. 从固定源提交提取 UFL 和源闭合体积头文件，重新生成 C++ 组装代码，不使用源工作目录中已修改的旧生成头文件。
2. 独立组装两种变形上的零压力/8 mmHg 力、切线作用和伸长投影右端。
3. 比较 PyTorch 被动力、内膜压力力、完整源力、被动/压力/完整切线及一致投影右端。
4. 比较源闭合体积、源开口 UFL 体积和 AFSEI 闭合体积，量化两种压力载荷下的平衡差别。

参考过程在独立、干净的 FEniCS 子环境编译运行，不向 AFSEI 环境安装 DOLFIN，不修改原电–力或 AFSI_GPU 仓库。检查是固定原 UFL 在收敛变形上的独立弱平衡验证；不是运行原程序整拍，也不要求两套 Newton 的迭代过程逐位相同。

结果与误差记录见 [PRELOAD_SOURCE_VALIDATION.json](PRELOAD_SOURCE_VALIDATION.json)。

真实网格为 26889 个心肌节点、135430 个心肌单元；两组计算都保留源材料和输入参考几何：

| 8 mmHg 加载末端 | 纯固体内膜压力对照 | AFSEI 闭合界面 |
| --- | ---: | ---: |
| 闭合腔体积，ml | 136.789324 | 138.322716 |
| 对应压力模型的真实力残差，dyn | 1.9943e-4 | 1.9872e-4 |
| `max abs(Zs)` | 0.07402675 | 0.07402357 |
| `max abs(Zw)` | 0.00709504 | 0.00709469 |

未加载参考腔体积为 68.330348 ml；两组加载后的体积相差 1.533392 ml，约为源结果的 1.12%。两组均满足 `1e-3 dyn` 力容差。可见较大的充盈量在源被动问题中也存在，不能简单归因于增加封口压力；仍需核对未加载几何假设、初始应力及生理参数。

在源平衡变形上，PyTorch 被动力与独立原 UFL 的相对差约 `9.95e-12`；压力力约 `3.73e-16`，完整切线作用约 `1.53e-14`。独立源闭合体积与 AFSEI 的差低于 `1e-9 ml`。平衡点上完整残量接近零，按分量绝对误差检查，其最大差约 `6.12e-9 dyn`。

把闭合界面的收敛变形放入纯固体内膜压力方程，会留下约 `2.6863e4 dyn` 的残差，与缺少的封口反力一致；这不是闭合流固平衡失败。两组最大节点位置差约 `0.149105 cm`。当前原基底约束允许两种载荷产生不同轴向反力，源纯固体的基底轴向合力约 `2.2431e5 dyn`，闭合载荷的基底合力接近零。

新的闭合预加载完成 100 个 5 ms 端点，无压力级拒绝，保存的初始固体/血液速度均为零。预加载体积与第七阶段静态结果之差仅约 `7.6e-9 ml`；改变的是进入首次刺激的机械历史，而非最终被动平衡方程。

## 使用

```bash
cd /mnt/large2/gjh/AFSEI
source scripts/activate_afsei.sh
python scripts/prepare_afsei_preload.py --write-vtk --output results/my_source_history_preload
python scripts/run_afsei_two_way.py --resume results/my_source_history_preload/checkpoint.npz --duration-ms 0.2 --write-vtk --output results/my_source_history_02ms
```

预加载默认 `--history-mode source-ramp`，保存 100 个加载端点的应变历史，腔压/心房压力 8 mmHg、动脉电容压力 85 mmHg。原参考几何保留，固体和血液初始速度为零。EP 的首次刺激时钟仍为 500 ms；RCR 从首次物理推进开始演化。

`--history-mode static-zero-z` 保留第七阶段静态对照。旧检查点继续恢复旧历史，不会在续算时自动补造 500 ms 的加载过程。需要新的加载历史时，应新建预加载检查点。

独立源对照入口：

```bash
python scripts/check_afsei_preload_alignment.py --closed-checkpoint results/my_source_history_preload/checkpoint.npz --output results/my_source_preload_alignment
```

输出中的 `source_solid_preload.npz` 是带校验和、参考几何和材料绑定的纯固体对照数据，不是三场检查点。`--reuse-source-result` 可在重复独立组装时复用已完成的该文件，仍会重新核对其绑定和真实平衡。

## 血液网格和后续工作

本阶段测量了现有 8584 单元锥形血液验证网格的质量。采用
`q = 12 (3 V)^(2/3) / Σ(edge_length²)`，正四面体为 1。
参考状态最小值约 0.00841，中位数约 0.04753；约 99.31% 的单元低于 0.1。
8 mmHg 加载后中位数约 0.04873，最大“最长边/最小高度”约 294.34。
这说明它适合当前接口检查，不能据此声称空间收敛或可靠的整拍血流。

下一阶段需要用填充腔体内部的相容四面体网格替换单个中心点形成的细长锥体；保持原内膜、基底封口和理想化 MV/AV 边界，并使用有伴随反力回传的内部运动延拓。必须重新检查参考/加载网格质量、正体积路径、质量、几何守恒、界面虚功和三场重启，之后再延长计算时段。

当前仍没有真实瓣膜几何。完整心拍、射血与首次真实 AV 关闭后的全部 80 ms 张力下降、系统能量及空间/时间收敛仍待验证。输入几何继续假定为未加载参考；没有执行逆向初始应力求解。源弱平衡核对通过也不等于充盈体积已经完成生理标定。
