# 第二十二阶段：规定压力撤除与功配对 MAC 隐式交接验证

本阶段实现了去除规定内膜压力及其切线、同时联立心肌位移与基底反力的验证分支。
真实 GPU 试算表明该分支**没有通过静态压力交接**，因此未作为正式运行/检查点转换入口启用。
原检查点、源 EP/GPB/Land、预加载应变历史及 80 ms 空间张力卸载实现保持原配置。

## 从实际压力问题到新方程

第二十一阶段确认，固体侧规定内膜载荷与 MAC 压力场不是同一个量。
原预加载通过 `f_passive+basal + f_source_wall(8mmHg)=0` 保持静止，
其 MAC 压力为零。在正式压力交接中只撤除 `f_source_wall`，不会自动得到原几何上的流体静态平衡。

新 `TractionFreeCapProblem` 在原 BE–BE MAC 流体响应中求解：

```
unknowns = (dy, lambda_cap)
f_material = f_passive+basal(x_new) + f_active(x_new) + C_cap^T lambda_cap
f_MAC = S_old(f_material) - W_MAC^-1 B_cap^T lambda_cap
(u_new, p_MAC) = original_BE_flow(u_depart, f_MAC)
dy - dt*J_old(u_new) = 0
dt*B_cap(u_new) - C_cap(dy) = 0
```

该分支采用全基底闭合状态，不依赖解剖瓣膜。
没有规定内膜压力、额外腔压未知量或人为固定体积反力；
闭腔体积变化单独测量，不能由于基底通量闭合而假定它严格等容。
没有给 MAC 压力加常数偏移，没有外层完整 FSI 迭代或贴体流体网格。

新鲜构建的源模型配置把规定压力置零，从力和解析切线中一致撤除该项。
基底反力同时作用于流体和材料，采用原冻结几何、IB 体积 L2 速度投影、
解析被动/主动切线及缓存的基底 Schur 预条件器。
Newton、线性响应、CFL 和原机械收敛条件继续采用当前配置。
已有源压力/RCR 驱动不调用这个验证模块。

## 验证入口及拒绝发布规则

```bash
python scripts/check_afsei_mac_pressure_handoff.py \
  --checkpoint results/phase10_mac128_source_preload_v1/checkpoint.npz \
  --steps 3 --output results/my_pressure_handoff_check
```

只接受未推进的源规定压力 MAC 预加载检查点：初始流体静止、压力为零、
100×5 ms 预加载应变历史已核对、Land 主动载荷关闭。
已激动的 500.2/517 ms 状态不是静态预加载，不能被静默替代。

先执行并丢弃一个原规定压力静态对照步，确认输入预加载本身满足原限制；
然后在新建的无规定压力模型中执行并丢弃 1–20 个机械/流体试步。
原 EP、门控、Land 应变历史、原几何和检查点时钟均不推进。
输出仅为 `report.json`，没有生成可误续算的“正式交接”检查点。

静态交接检查采用原预加载的位移 L2 ≤1e-9 cm、最大流速 ≤1e-6 cm/s；
同时检查核心区均压与 8 mmHg 差 ≤0.05 mmHg、闭腔体积差 ≤1e-3 ml、
基底相对流量范数 ≤1e-5 ml/s、配对功相对误差及闭合总功相对误差 ≤1e-7。
压力/功等补充指标单独标记为静态交接工程检查，不改变正式推进的收敛阈值。
失败指标逐项记录；`status=completed` 只表示检查完成，
是否满足交接由 `static_handoff_validated` 表示。
本模块没有正式发布候选状态的接口，`production_handoff_enabled=false`。

MAC 最大散度小于 5e-13 s^-1，基底相对流量范数小于 2.1e-7 ml/s。

但静态位移、静态流速和预加载均压不满足交接要求。

严格的闭合总功指标也未满足：其相对残差约 1.16e-7–3.42e-7，
来自有限原 IB/基底残差对应的 `-lambda_cap·Q_relative`，

报告同时给出 `||lambda||*||Q_relative_projected||` 的功残差上界。
本阶段没有为消除该指标而放宽接受阈值或改动原机械求解容差。

第三步内膜表面采样的有符号/绝对相对通量约 2.09960/3.92523 ml/s。
这是局部滑移诊断，不能视为实际周期的净失血量。
全基底平均闭合、很小的 MAC 散度和单步体积差达标，都不足以证明静态内膜支承成立。

## 冻结材料投影为何不能替代联立求解

另一个保留在结果目录的只读试算 `results/phase22_source_free_probe_v1.json`，
先撤除规定载荷并求流体，再规定基底材料速度为零，执行原局部投影。
撤除载荷后的最大流速约 2.19678 cm/s，核心区均压约 6.78928 mmHg；
冻结材料投影后均压约 7.98366 mmHg，但最大流速仍约 1.76565 cm/s，
同时产生约 25467.649 dyn 的未施加材料反力。

因此，只看到“压力约 8 mmHg”不能认定预加载已经交接。
丢弃该反力或冻结实际心肌运动，会绕过原流固受力问题。
该临时试算不作为主线方法；真正的联立结果以本阶段新入口为准。

## 下一项实际修复

已经证实，源纯固体的规定压力平衡不能直接转换成原 MAC 的压力支承平衡。
下一项修复应建立**与原 MAC 离散一致的压力支承预加载问题**：

1. 将当前源预加载作为初始参考，明确真实内腔压力、外箱零压力、理想化盖面的支承与反力。
   同时平衡原流体压力/黏性作用和心肌力，不能单独调整显示压力或删去反力。
2. 若离散一致的平衡要求改变预加载后的几何，应生成独立的新结果，
   按源 100×5 ms 加载时钟重新积分对应几何的 Land 畸变历史；
   不能把旧 `zs/zw` 直接移植到新的加载路径，也不能覆盖已有检查点。
3. 先验证零主动张力的持续静止、8 mmHg 压力支承、闭腔质量与离散功，
   再连接实际 AV/RCR、等容舒张及源 80 ms 卸载事件。

这仍使用原规则 MAC 和隐式框架。内膜局部条件与基底支承的具体离散修正，
须从此平衡问题及误差来源确定；本阶段没有新增整面内膜约束或外层强耦合迭代。

## 性能与回归

三步试算不含 EP/GPB/Land 推进。最终对照第一步含基底缓存建立，约 8.50 s；
后两步分别约 1.20/1.08 s，样本很少，不能当作完整三场性能或双周期耗时。
正式 EP–FSI–RCR 每步仍参考第二十阶段约 1.32–1.33 s，
本阶段不增加正式步中的额外计算，也没有验证长周期性能改善。

新增三项实际 GPU 回归检查：无规定压力分支的完整有限差分切线、
真实非线性残差/基底功配对，以及失败交接后源几何/Land/检查点保持与拒绝活动状态输入。
完整相关回归 140 项全部通过，耗时 76.59 s。
