# 第七阶段：8 mmHg 被动预加载与三场初始化

本阶段在首次刺激时刻之前求心肌与闭合血液界面的静态机械平衡，然后保存可由双向三场驱动继续推进的检查点。加载参数不是物理时间；该过程不推进电位、GPB、Land、刺激时钟或外周电容压力。

## 平衡方程及参考状态

保留输入心肌几何 `X`、材料方向与原材料参考，不把预加载变形 `x_pre` 重置为零应变参考。该选择假定输入几何未加载；没有执行逆向卸载或反演初始应力。若输入网格来自已加载的成像状态，仍需另行处理这一假设。

预加载将压力从零逐级增加至目标值，求解

\[
F_{\rm passive}(x)+F_{\rm basal}(x)+p\nabla_x V(Hx)=0.
\]

`H` 是拟合血液网格到心肌节点的既有线性运动映射。压力力用 `H.T` 返回心肌节点。`V` 为当前闭合血液域体积，压力单位换算为 `1 mmHg = 1333.22368421 dyn/cm²`。

压力作用于整个闭合界面，包含理想化基底盖面。这与双阀关闭的实际血液压力反力一致；与仅在内膜施加压力的纯固体载荷具有盖面反力的差别。三场推进时仅使用血液界面反力，不再叠加第二份内膜压力。

预加载主动应力为零，保留源被动本构、源基底弹簧、体积分与基底积分规则。Newton 使用原本构力及其完整切线、压力随形切线、残量下降回溯。该本构的原论文能量表达式不能替代修正 PK1 的力方程。

线性子问题使用 GPU PyTorch 稀疏切线、GMRES 和平滑粗空间预处理。粗空间仅改善收敛，不修改材料、不可压缩参数或最终力平衡条件。所有加载级均检查真实残量，以及心肌和血液四面体沿变形路径的正体积。失败减半压力增量；仅保留已收敛的加载状态，不能把最后一个未收敛 Newton 迭代当作完成结果。

## 初始血液、循环和电状态

成功加载后初始化 `u_blood = 0`、`v_solid = 0`，腔内压力为目标压力。心房压力同时设为目标值，默认 `8 mmHg`。原端口测试的 `8.5 mmHg` 会在静止的 `8 mmHg` 腔体中产生流入，因此不用于这一静态初始化。

动脉电容压力默认仍为源项目的 `85 mmHg`；MV/AV 初始关闭，检查阀门压力不等式和实际静态血液反力。心肌伸长用预加载变形重新投影；GPB/Land 初始状态保留，机械应变率历史初始化为零。首次刺激后才开始 EP/ODE 和 RCR 时间推进。

这是**机械平衡初始化**，不是整个循环的稳态。默认外周静脉压力为 `8 mmHg`、远端阻力为 `1.05 mmHg·s/ml`，初始外周流出为 `(85-8)/1.05 = 73.333333 ml/s`。因此即使 AV 关闭，时间推进后电容压力也会下降。

第八阶段进一步检查固定版本的源程序，确认原程序在预加载期间也冻结电位、GPB 和 Land 门控状态；此前关于缺少 EP/ODE 静息重放的推测已纠正。第七阶段实际缺少的是每个已接受机械加载步产生的伸长与 `Zs/Zw` 历史。第八阶段将默认入口改为保留 100 个 5 ms 端点的应变历史；本页数值仍记录第七阶段的零历史对照，旧检查点不会被自动改写。首拍完整波形仍需验证。

## 运行

```bash
cd /mnt/large2/gjh/AFSEI
source scripts/activate_afsei.sh
python scripts/prepare_afsei_preload.py --history-mode static-zero-z --write-vtk --output results/my_preload_8mmhg
python scripts/run_afsei_two_way.py --resume results/my_preload_8mmhg/checkpoint.npz --duration-ms 0.2 --write-vtk --output results/my_preloaded_two_way_02ms
```

预加载输出 `summary.json`、逐级 `loading_history.json`、完成后的三场 `checkpoint.npz`，以及可选心肌/血液 VTK。输出目录必须新建或为空。失败时另存最后已收敛加载状态供诊断；该文件不是可由三场驱动直接续算的完成检查点。

`--target-pressure-mmhg`、`--initial-pc-mmhg`、`--pressure-step-mmhg` 调整压力；三场步长默认 `0.1 ms`。加载结束仍停留在首次刺激 `500 ms`，后续 `--duration-ms` 为追加的物理时间。原未预加载入口仍可用于接口对照。

## 验证边界

测试覆盖压力力与体积导数、压力切线及对称性、CPU/GPU 一致公式、粗空间仿射模式、小网格被动平衡、零初始速度、不推进电状态、参考不重置、检查点往返及首次三场步进、失败回退，以及不相容初始心房压力的拒绝。

真实网格使用 26889 个心肌节点、135430 个心肌单元和 8584 个血液单元。13 个加载级均通过真实力平衡，达到 8 mmHg，无加载级拒绝；约耗时 407 秒（同时运行部分回归测试）。腔体积由 68.330348 ml 增至 138.322716 ml，最大位移 1.275752 cm，最小固体 Jacobian 为 0.894075。最终力残差 1.9724e-4 dyn，容差 1e-3 dyn，相对残差 5.5698e-9。

完成的检查点先推进 0.2 ms，再从该检查点继续到刺激后 1 ms，共 10 个机械步、20 个 EP 步和 500 个 ODE 子步，无拒绝。首次 0.2 ms 主动载荷仍低于机械容差；后续区间出现非零固体/血液运动，最终腔压 8.000230 mmHg，心肌最大速度 0.002882 cm/s。双阀持续关闭，最大质量误差 2.7032e-10 ml/s，最大界面虚功误差 7.7716e-16 erg/s；每个机械步的真实动量残差均通过容差。动脉电容压力下降至 84.943612 mmHg。

这些数值说明初始化和短程三场推进相容。第七阶段尚未与源纯固体的 8 mmHg 预加载体积作数值对照；后续独立对照见 [第八阶段](PRELOAD_SOURCE_PHASE8.md)。较大的体积变化仍不能直接解释为已核对的生理舒张状态。

详细数值记录见 [PRELOAD_VALIDATION.json](PRELOAD_VALIDATION.json)。当前血液网格仍是锥形验证网格。本阶段不宣称完成高质量血液网格、完整心动周期、射血/真实闭瓣事件验证、全系统能量平衡或与纯固体整拍波形一致性。
