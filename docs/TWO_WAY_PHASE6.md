# 第六阶段：拟合血液与心肌双向耦合

基线：`a6c04d1352ee25268d0141200db81d0e485f0d97`。
本阶段新增独立的 `afsi_torch.two_way` 驱动，用左心室血液反力替换第五阶段
单向驱动中的开放外箱流体。早期驱动保留作分模块验证。

## 联立方程

心肌仍使用源项目的材料、基底约束、积分规则和 EP–GPB–Land 主动 PK1 载荷。
心肌节点增加明确的集总质量

\[
M_{s,a}=\rho_s\sum_{K\ni a}V_{K,0}/4,\qquad\rho_s=1\ \mathrm{g/cm^3}.
\]

每个机械时间步联立求解

\[
v_s^{n+1}=(x_s^{n+1}-x_s^n)/\Delta t,
\qquad M_s(v_s^{n+1}-v_s^n)/\Delta t
=F_{passive+basal+Land}(x_s^{n+1})+F_{blood}^{n+1}.
\]

这是动态流固模型；源纯固体项目的准静态平衡没有惯性项，因此完整运动曲线不会自动相同。
没有增加预设内膜压力、RCR 固体压力或旧主动收缩波形。血液反力只作用一次。
EP 单域 PDE 仍由 PyTorch GPU 计算，GPB/Land 使用现有 CUDA ODE 内核。
机械步内先以已接受的伸长历史推进 EP/ODE，再联立流体与固体，成功后发布新的伸长/Z 历史。
这是分区三场时间积分，不是 EP、流体、固体统一的单体 Newton 方程。

血液保持第五阶段 CR 面速度/P0 压力、黏性预测和压力投影离散。
由心肌 P1 插值获得移动血液网格；移动三角面的扫掠面积与网格流量满足几何守恒。
墙面和关闭端口满足 `u=w`。端口采用相对网格的实际流量：

\[
Q_j^{out}=\int_{\Gamma_j}(u-w)\cdot n\,dA,
\qquad \dot V+Q_{MV}^{out}+Q_{AV}^{out}=0.
\]

RCR 后向 Euler 更新为

\[
C(P_c^{n+1}-P_c^n)/\Delta t
=Q_{AV}^{out}-(P_c^{n+1}-P_v)/R_p,
\quad P_{AV}=P_c^{n+1}+(R_c+R_{AV})Q_{AV}^{out},
\quad P_{MV}=P_{at}+R_{MV}Q_{MV}^{out}.
\]

两个阀门独立检查开阀流向和闭阀侧的平均反力压力不等式。
双阀关闭时，腔压的常数部分成为固体方程中的未知量，并增加

\[
V(x_s^{n+1})-V(x_s^n)=0.
\]

不再像第五阶段单向驱动那样从一个压力区间任意选取压力规范。
内层非线性试算可能暂时改变总体积：此时只在试算中把封闭压力 RHS 投影到均值为零的空间，
由外层固体/体积方程消除不相容性。最终接受前检查原始物理单元散度、总质量和体积变化率；
没有在接受后修改坐标、补偿端口流量或添加隐含漏流。

## 反力与收敛

面反力从离散流体运动方程的固定自由度残差取得，并通过相同 P1 映射的转置传回心肌。
这样固体收到的力与流体受到的墙面力相反，且两侧离散功一致。
求解先使用固体解析稀疏切线、体积 Schur 预条件和端口流体附加惯性的一维修正，
再用 Anderson 迭代与包含流体方向导数的耦合 GMRES 修正。
方向导数通过新的、残差经过检查的 GPU 流体试算获得，没有对 PCG 的停止判断求自动微分。
网格、CFL 和真实残差保护非线性更新；最终必须满足固体运动方程与血液质量守恒。

固体默认力残差容差为 `max(1e-4 dyn, 1e-7 * max(||Fsolid||, ||Fblood||, 1))`，
关闭腔体允许的体积变化率为 `1e-8 ml/s`。
失败则丢弃整步 EP、GPB、Land、伸长、固体、血液、RCR 和阀门状态并减小步长，
最小步长为一个 EP 步 `0.05 ms`。

## 主动张力快速下降

首次实际射血必须为 **MV 关闭、AV 打开且 AV 正向流动**。
首次已接受的 AV 关闭才触发卸载，固定腔体的双端口被动流通不会制造这个事件。
在该次固体求解实际使用的 `force_load` 历史下提取关闭时的积分点张力，
避免发布伸长/Z 后把同一次伸长更新计算两遍。

\[
T_a^{applied}(X,t)=T_{close}(X)\max(0,1-(t-t_{close})/0.080).
\]

Land 回到首次刺激前的快照、Z 清零，GPB/Vm/Ca 保持连续。
这一线性下降作用于张力标量，完整主动 PK1 力仍依赖当前变形与纤维伸长。
与源纯固体模型的人为全程等容卸载不同，流固模型只在实际双阀关闭时约束体积；
MV 达到重新打开的压力条件后允许充盈，80 ms 张力下降仍按原规律继续。

## 运行与续算

```bash
cd /mnt/large2/gjh/AFSEI
source scripts/activate_afsei.sh
python scripts/run_afsei_two_way.py --duration-ms 0.2 --write-vtk --output results/my_two_way_02ms
python scripts/run_afsei_two_way.py --resume results/my_two_way_02ms/checkpoint.npz --duration-ms 0.2 --output results/my_two_way_04ms
```

默认 EP 步 `0.05 ms`、ODE 子步 `0.002 ms`、机械步 `0.1 ms`。
`--resume` 恢复已保存的所有物理配置，`--duration-ms` 是追加时间。
三场检查点为数值数组/JSON/校验和，包含固体速度、实际血液速度/压力、RCR、EP/ODE 和主动力历史。
原外箱或单向检查点使用不同的物理状态格式，不能直接作为本驱动的续算起点。

`summary.json` 分别标记三场双向时间积分、预加载和完整心动周期验证状态。
`history.csv` 记录固体残差、质量、体积、界面虚功、阀门和实际施加张力。
