## Notebook 的等容约束

代码单元 5 的 `Isovolumetric_PressureUpdate` 固定当前步主动张力，
改变腔压并重复求解固体平衡，使：

```
G(p) = V(x(p)) - Vtarget = 0
p_next = p - G(p) / (dV/dp)
```

其中 `dV/dp` 用 0.01 kPa 的压力扰动估计。
代码单元 6 在等容收缩与等容舒张均调用这个函数。
等容收缩的概念目标是舒张末体积，等容舒张的概念目标是射血末体积；
腔压随主动收缩和卸载变化，是待求解量。
等容不要求心肌形状、位移或壁内运动保持静止。

直接复制实现有两个需要修正的地方：

1. Notebook 每个接受步将 `vol_pre` 更新为近似求解体积，可能积累体积误差。
   AFSEI 应保留电–力项目的守恒目标，闭阀期间不因求解残差逐步漂移。
2. Notebook 用压力迭代增量 `abs(p_next-p)<0.01 kPa` 判断收敛，
   不能据此确认体积残差已满足要求。应同时检查实际力学残差和体积残差；
   固定电–力参考的体积容差为 1e-3 ml。

当前 MAC 主线尚未接入这两阶段的体积约束。
第十三阶段的非端口局部平均法向约束不能代替全腔体等容约束，
也不意味着理想化 MV/AV 已关闭。

## Notebook 的射血关系与现有 RCR 的区别

代码单元 5 的 `PressureUpdatePhase3` 求解：

```
V_next - V_old + C_art*(p_next-p_old)
    + dt*(p_next-P_o)/R_per = 0
```

它对应理想开放出口下的简化两元 RC 关系：

```
Qout = -(V_next-V_old)/dt
C_art*(p_next-p_old)/dt = Qout - (p_next-P_o)/R_per
```

该函数没有独立的近端阻力 Rc，也没有独立于 LV 腔压的电容压力状态。
当前 AFSEI 独立循环模块采用三元 RCR：

```
C*(pc_next-pc_old)/dt = Q_AV - (pc_next-Pvenous)/Rp
p_AO = pc_next + Rc*Q_AV
```

在 Rc=0、忽略开放阀压降且 pLV=pc 的理想射血极限下，
RCR 的这一支路与 notebook 的 RC 体积关系相对应。
本次参考核对没有切换电路形式或替换 RCR 参数。

接入流固后，`Q_AV` 必须来自实际相对瓣口流量，
`dV/dt = Q_MV-Q_AV` 用于质量一致性核对。
源纯固体/Notebook 中的体积推导流量不能在 FSI 中替代独立实际瓣口流量。
两阀关闭且其余腔壁不透流时，该关系退化为等容。
开放射血或充盈时应解除固定体积条件，避免阻止正常容积变化。

Notebook 的射血函数混用 kPa→Pa、ml→m³ 和 s→ms 的数值转换，
常数 C_art、R_per、P_o 需要核对单位后才能用于项目参数。
配置中的 `p_target=1.066580 kPa` 实际约为 8 mmHg；
`p_aorta=11.5 kPa` 实际约为 86.26 mmHg，与旁边注释的 45/63.75 mmHg 不符。
不直接复制注释中的压力或未核对的常数。

## 主动载荷与卸载仍按电–力源项目

Notebook 的 `AT_func` 使用 `active_tension_900ms.txt` 的预设标量波形。
AFSEI 继续使用空间分布的 EP→GPB 钙动力学→Land 张力及源主动 PK1 载荷。
不采用 notebook 的张力文件、Tmax 或其 0.9 s 周期。
现有源刺激时刻 0.5/1.3 s、EP=0.05 ms、ODE=0.002 ms 保留。

卸载采用电–力源项目在接受的真实 AV 关闭时刻保存的空间张力快照，
按源 80 ms 线性过程降至零，保留源历史重置与事件提交规则。
Notebook 的 `isoVolumetrix_relaxation_extra` 同时规定压力和张力降至周期末，
不执行体积压力求解，不能当作已经满足等容的卸载过程。
该额外舒张函数不采用；也不直接复制 `Ta<=0.1`、`p<0.2 kPa`
或周期结束等经验阶段退出条件。充盈切换须与选定循环边界和源卸载协议相容。

## 几何与求解实现

Notebook 仅在内膜上积分 `-1/3*x_def·n_def`。
该表达式在缺少基底通量时不能普遍作为闭合腔体体积。
AFSEI 保留已经对齐的内膜＋随基底边缘运动的封面体积及其精确微分。

等容求解应纳入原 MAC 隐式残差及线性化，复用现有线性响应和预条件器。
不直接增加 notebook 式的外层压力试探循环，以免每次试探重复完整流固求解。
流体压力、约束反力、端口压力载荷需要核对离散功，避免重复施加腔压。
本参考记录没有启用额外迭代、改变网格或修改正式时间推进。
