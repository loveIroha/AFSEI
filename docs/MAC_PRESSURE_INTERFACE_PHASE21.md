# 第二十一阶段：MAC 压力、源内膜控制载荷与局部界面通量核对

本阶段增加独立诊断入口，不推进循环、不修改已有检查点，不增加正式时间步中的求解。
沿用原 128³ MAC、BE–BE 隐式流固、PyTorch EP 和 CUDA GPB/Land。
源主动 PK1、伸长反馈、80 ms 空间张力卸载及原收敛阈值保持原实现。

## 为什么先核对压力

第二十阶段已实现实际相对 AV 流量/RCR 的同一步数学联立，但不能据此认为
其中名为 `cavity_pressure_mmhg` 的量就是实际血液压力。

当前离散载荷可写成：

```
f_material = f_passive+basal + f_EP/Land + f_source_wall(p_control) + C_cap^T lambda
f_MAC = S_old(f_material) - W_MAC^-1 B_cap^T lambda
u_star = (I-dt*mu/rho*L)^-1 (u_depart + dt/rho*f_MAC)
A_D p_MAC = -rho/dt*D u_star
u_new = u_star - dt/rho*G_D p_MAC
```

`f_source_wall` 是源电–力模型的当前内膜 follower 载荷，仅作用于内膜，未包括虚拟盖面。
固定 8 mmHg 预加载载荷在后续步中仍被保留；等容/RCR 模式用待求的控制量替换其数值。
`lambda` 是基底流体/材料通量约束的功配对乘子。
`p_MAC` 是压力投影独立求出的全外箱场，单位 dyn/cm²，外箱物理边界为零。

三个量的定义不同。非定常流动中，腔内平均压力与端口压力也不必相等。
不能通过平均压力和乘子之间的差异单独推断端口方程有错误，
但必须进一步建立各自与真实内腔压力、壁面应力及外部压力的对应关系，才能用于生理阶段切换。

本阶段的压力分解分别计算上述载荷的零历史流体响应，用独立的合并响应核对线性叠加。
实际保存压力减去各载荷响应之和的余量标为时间/对流余量；
检查点没有保存接受步之前的完整流体速度，**没有重建该步的对流历史**。
该余量不是一个被独立验证的完整推进重建。

## 新入口和诊断范围

```bash
python scripts/check_afsei_mac_pressure.py \
  --checkpoint results/phase20_mac128_rcr_coupled_native_v2/checkpoint.npz \
               results/phase20_mac128_rcr_coupled_open_probe_v2/checkpoint.npz \
               results/phase16_mac128_closed_cap_from_preload_v1/checkpoint.npz \
  --output results/my_mac_pressure_audit
```

脚本读取并验证原检查点及校验和，输出 `report.json`。
默认内膜求积等级为 1/2/3，腔内核心区排除靠近内膜及盖面的两格 Chebyshev 带。
核心区分类只是在**现有 MAC 压力单元**中选取统计样本，未建立额外流体网格或血液求解器。
可用 `--guard-cells 1` 等检查选区敏感性，用 `--levels 2 3 4` 检查更细求积，
或用 `--skip-force-decomposition` 跳过仅用于诊断的 6 次线性流体响应。
诊断用的保护带、求积及工程指标不会改变正式推进的接受阈值。

内膜分别在接受步前的冻结几何和当前几何上积分。
盖面按原端口算子的固定四级表面积分报告非端口/MV/AV 区域，
同时保留原生有限步体积平衡与旧几何相对出口流量，避免把当前几何流量冒充求解中的流量。
开放 AV 的正常相对通流排除在关闭表面绝对滑移统计之外；
关闭状态则包括整个盖面。原算子的盖面求积未在本阶段另作空间收敛证明。

## 载荷修正的下一步

1. 以流体实际压力/黏性应力与心肌应力传递为正式循环的受力关系，
   重新建立规定压力预加载向物理流体压力支承的交接。
   当前规定内膜载荷只能作为源预加载/控制参考；不能在已有流体压力反馈上再叠加同一血压载荷。
   交接必须保留源预加载几何与 Land 应变历史，并先通过零主动张力的静态平衡检查。
   单独删除载荷而不重建压力/边界平衡也不能视为完成交接。
2. 推导端口乘子对应的压力跳跃、盖面内外压力和配对反力，核对离散功。
   RCR 应连接此处的物理相对压力/实际流量关系；不把源控制量直接塞进原有端口压力公式。
3. 在同一个原 MAC 隐式求解框架内核对关闭边界、有限步体积守恒和局部界面质量。
   若保留全腔约束反力，应明确其物理意义，避免与压力传递重复计力。
   不增加外层完整 FSI 重复求解，也不通过放宽容差掩盖流量或功的不一致。
4. 上述平衡和压力对应成立后，再连接实际 AV 开闭、源 80 ms 卸载、固定 ES 体积等容舒张、
   源平滑规定压力充盈及第二次激动，并完成完整周期验证。

原 MAC 压力外边界为零 Dirichlet。把整个压力场加 1 mmHg 会在外边界产生非零离散梯度，
所以这不是可自由选择的零均值压力规范。只给腔内加常数也会产生界面压力跳跃，
需要相应的应力/载荷项；本阶段不实施未经推导的常数偏移。
