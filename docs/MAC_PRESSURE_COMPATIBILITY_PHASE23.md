# 第二十三阶段：静态压力载荷兼容性与压力预加载前置验证

本阶段完成原 Cartesian BE–BE MAC 上的静态压力载荷对照入口，并实现一个独立的边界压力传递候选。
**尚未完成新的压力支承预加载，也未发布压力交接检查点。**
已有源规定压力预加载及第二十二阶段联立基底反力的失败结果继续保留。

## 为什么先核对压力载荷

源预加载满足节点力平衡：

```
F_passive+basal(x0) + F_source_endo(x0,8mmHg) ≈ 0
```

这不能直接证明撤去规定压力之后，现有体积 L2 力传递 `S` 给出的流体载荷是
MAC 离散压力梯度。非梯度部分会经压力投影保留下来，产生残余速度。
重新加载几何前，需要区分这种离散误差与缺失基底压力/反力。

所有对照使用相同的 128³ MAC 网格、13 cm 外箱、0.1 ms 时间步、流体参数、
零 Dirichlet 外箱压力、已有 Helmholtz 和压力求解器。
腔体掩码只选取现有压力单元并定义制造解，不构造新的流体网格或求解域。

## 对照方程与适用范围

原流体响应是：

```
H u_star = dt/rho * f,   H = I - nu*dt*L_velocity
A_D p = -rho/dt * D u_star,   A_D = -D G_D
u = u_star - dt/rho * G_D p
```

离线检查用同一个 `A_D` 分解载荷：

```
A_D q = -D f
f = G_D q + f_remainder
```

报告的 `non_gradient_density_fraction` 是用原 MAC 面权重计算的
`||f_remainder|| / ||f||`，不是质量损失百分比或运行误差容差。
制造静压对照指定腔内 8 mmHg、腔外零的单元压力 `p_target`，实际施加
`f = H G_D p_target`，再调用原流体响应验证 `u≈0,p≈p_target`。
这验证当前分裂算子的压力平衡能力；它是制造载荷，**不是生理预加载，不能直接用于正式心肌驱动**。
没有给求出的压力加任意常数。

实际载荷比较包括：

1. 去除规定内膜压力后的源被动/基底节点力，经原 `S` 传递。
2. 原 `S(-F_source_endo)` 加上单独的流体基底压力。
3. 血液外法向上的完整壁面与基底盖面压力 `-p n`，直接用原四点 Peskin 表面核传递。
4. 同样的闭合表面压力，用局部复合 BS4–BS3 核传递。
5. 上述制造 MAC 梯度载荷。

第 2–4 项的基底载荷仅用于**隔离流体压力载荷误差**，没有加入配对材料反力。
它们不是完整 FSI 静态状态，不取代第二十二阶段的位移/反力联立检查。
没有把源内膜规定压力改成完整体积梯度，也未双重施加到正式流固方程。

## 局部候选的实现

复合核的速度分量正常方向使用四点支撑的三次 B 样条，两个切向方向使用三点支撑的二次 B 样条。
三维单点支撑为 4×3×3=36 个面自由度；原各向同性四点核为 64 个。
候选的表面速度采样与压力传递使用相同权重，边界功配对用实际 GPU 测试验证。
压力积分分批执行，保持有限临时内存，禁止核支撑触及外箱。

该局部结构的压力梯度保持性质可参考原始论文
[Gruninger & Griffith, Composite B-Spline Regularized Delta Functions](https://arxiv.org/html/2408.08280v3)，
尤其是第 3.5 节。该性质要求闭合压力表面积分足够准确；本代码中的有限积分仍需收敛检查。
论文性质不能直接证明当前厚壁 FE 节点力的体积 L2 传递、基底反力和完整三场状态已兼容。

`FETransfer`、正式基底/端口核、源 PK1 与解析切线没有更换。
本阶段没有新的流体网格、额外外层 FSI 迭代、压力偏移或周期控制器。

## 真实 RTX 4090 结果

输入保持第二十二阶段同一未推进预加载：

```
results/phase10_mac128_source_preload_v1/checkpoint.npz
SHA256 fc5e9ee27aad97cc31c6e90ad0835c2c4691cb896a29bfaa8d5d13ede23227d8
```

源节点残余力范数为 0.00019942859 dyn。结果：

| 孤立流体载荷 | 腔内均压 mmHg | 最大速度 cm/s | 非梯度比例 |
|---|---:|---:|---:|
| 源材料力，撤去规定压力 | 6.789280875 | 2.196779674 | 0.163926112 |
| 源内膜体积传递 + 流体盖面，level 4 | 7.995163280 | 1.758555666 | 0.089529519 |
| 闭合 Peskin 表面，level 3 | 7.999688254 | 0.084329501 | 0.012757531 |
| 闭合 Peskin 表面，level 4 | 7.999688289 | 0.084276009 | 0.012755298 |
| 闭合 BS4–BS3 表面，level 3 | 7.999999984 | 0.020379031 | 0.000370479 |
| 闭合 BS4–BS3 表面，level 4 | 7.999999958 | 0.003618463 | 0.000059614 |
| 制造离散静压对照 | 7.999999995 | 2.15256e-9 | 2.93193e-10 |

壁面使用 level 3/4，长基底扇形分别使用 level 5/6；此前 level 2/3 对照也已运行。
原核闭合表面速度已接近加密稳定值；复合候选仍明显受积分误差影响，
最终速度约为原闭合表面核的 1/23，但仍高于原静态速度验收限 1e-6 cm/s。
因此既不能宣称候选已经静止，也不能仅根据约 8 mmHg 均压启用完整周期。
制造解全压力场最大误差为 8.90421e-9 mmHg。

这些证据说明，在原几何上补齐流体盖面载荷能够改善均压，但不能消除现有体积力传递的残余速度。
压力求解器具备离散静压平衡能力；正式修复需要同时处理载荷离散、材料反力及预加载路径。
这不是证明当前几何上的每一部分误差都来自核，也不代表单独改核即可完成 FSI。
