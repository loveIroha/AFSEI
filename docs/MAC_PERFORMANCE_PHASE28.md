# 第二十八阶段：保留隐式 MAC 的性能优化

本轮继续使用原 Cartesian MAC、BE 隐式黏性与压力投影及联合心肌/基底约束。
单域 PDE、GPB/Land、主动应力及源项目卸载规律、材料参数、步长和物理验收阈值不变。
没有增加外层完整 FSI 迭代。没有接入显式黏性方案。

## 保留的修改

* 心肌切线装配默认分批由 2,048 改为 8,192 个单元；积分公式与 CSR 结构不变。
* 流体默认先完成一个 Jacobi 检查块，再读取 GPU 残差和 RHS 范数，省去初始同步。
  求解的是同一个隐式 Helmholtz 矩阵；仍用原绝对/相对容差验证真实残差。
  全局 `BEFlowOptions.initial_sweeps` 默认仍为 0；仅此 AFSEI 分支启用首块预推进。
* 当前物理步内，相同未知量与未变旧几何的残差直接复用；返回独立副本。
* 合并 P1 压力模式导数并融合为 GPU 核函数。边界力导数对几何为仿射函数，因此
  `(2 DF((x_old+x)/2)+DF(x))/6 = DF((x_old+2x)/3)/2`，该变换是代数等价的。
* 默认采用步内机械切线复用的 modified Newton–GMRES。每个物理步重新建立机械切线；
  不跨步、不跨 EP/Land 状态复用。阀门开放分支改变或候选几何移动达到 0.05 个 MAC 单元时刷新。
  压力模式几何导数、约束行及完整非线性残差仍按当前候选状态计算。
  这是近似 Newton 线性化，不宣称每次使用当前精确机械雅可比。
  线性/非线性真实残差和 Armijo 标准保持原值；失败时从最后接受的候选点转用逐次刷新切线的 Newton，
  最终目标保留原始初值确定的容差。仍失败则执行已有的物理步回退。

检查点记录 `balanced_tangent_chunk_size`、`helmholtz_initial_sweeps`、`reuse_step_tangent`。
旧格式缺失这些执行字段时使用本轮默认配置；材料和全部物理历史从原检查点恢复。
正式周期入口支持 `--no-reuse-step-tangent` 关闭步内机械切线复用，续算也可显式覆盖该执行设置。

## 已完成的 GPU 实验

RTX 4090，float64，26,889 节点、135,430 固体单元，原 `128³`、13 cm MAC 流体网格。
同一个已接受的 560 ms 输入：`results/phase25_mac128_balanced_rcr_native_60ms_v5/checkpoint.npz`。
各组走 1 步初始化，再计时 5 步，CUDA 同步计时包含 EP/ODE、FSI 与接受诊断，排除文件输出。
基线为上一轮 `2a3d280`，dt=1e-4 s。

| 版本 | 平均秒/步 | 相比上一轮 |
|---|---:|---:|
| 上一轮 | 2.339311 | — |
| 分批、黏性检查调度和残差缓存 | 2.218893 | 耗时减少 5.15% |
| 最终方案，含步内切线复用和合并导数 | 2.172297 | 耗时减少 7.14% |

最终五个暖步为 2.228、2.253、2.167、2.103、2.111 s；首次初始化步约 13.56 s。
机械切线装配每步从 4 次降为 1 次，但 Newton 修正为 4–6 次，GMRES 为 48–51 次，
流体响应为 57–64 次。因此本轮主要减少装配和同步成本，没有解决联合系统 Krylov 响应次数偏多的问题。
所有六步无物理步回退；最大质量误差 4.93e-10 ml/s。

按 16,000 步、两个 800 ms 周期外推约 9.65 h，比上一轮约 10.40 h 少约 45 分钟。
这仅是射血初段短窗口外推，不含启动/文件输出、其他阶段差异和回退；本轮没有运行完整周期。
尚不能据此声称回到 AFSI_GPU 完整两周期的约 4.5 h。
本轮没有重跑已完成的其他步长性能实验，也没有将上一轮 5e-5 的计时作为新代码的性能结果。

最终方案暖步平均分段：GPB/Land 0.05753 s、单域 PDE 0.01736 s、隐式 FSI 2.07676 s、
载荷准备及应变反馈合计 0.01996 s。EP/ODE 直接推进仍只占约 3.45%。

本轮已完成的方案均保留服务器结果，不再重复运行：

## 使用

正式后台运行仍使用 `scripts/run_afsei_cycle.py`；已有启动与续算命令不变。
需逐次刷新机械切线时添加 `--no-reuse-step-tangent`。

性能脚本现在可显式控制分批大小、初始黏性扫掠与机械切线复用：

```bash
python scripts/benchmark_afsei_balanced.py \
  --input results/phase25_mac128_balanced_rcr_native_60ms_v5/checkpoint.npz \
  --output results/my_short_performance_check \
  --steps 5 --warmup 1 --tangent-chunk-size 8192 \
  --helmholtz-initial-sweeps 4 --reuse-step-tangent
```

该命令仅供后续需要新的对照时使用，本轮同配置实验已完成，无需再次运行。
