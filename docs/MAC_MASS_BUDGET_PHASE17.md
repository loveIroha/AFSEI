# 完整表面质量预算与基底面片加密

本阶段保留原 AFSI_GPU 的 128³ 规则 MAC 网格和 BE–BE 隐式流固求解框架。
新增只读诊断及预条件器缓存优化；没有改变源材料、EP/GPB/Land、主动 PK1、固定体积目标、
接受 AV 关闭后的空间张力快照和 80 ms 线性卸载，也没有增加外层完整 FSI 迭代。
闭合阶段 RCR 仍按假定 Q=0 更新，实际端口流量和完整心动周期尚未接入。

## 为什么检查完整表面

原 IB 运动方程采用体积 L2 投影 J：位移满足 y = dt J u。
直接在内膜/盖面取四点 Peskin 核流速，与有限元边界材料速度比较，是另一种局部诊断。
它们的差不能直接认定为原隐式运动方程未收敛。

对血液向外法向，诊断分别计算

\[
Q_u=\int_{\Gamma}u\cdot n\,dA,\qquad
Q_w=\int_{\Gamma}w\cdot n\,dA,\qquad
Q_{rel}=Q_u-Q_w,\qquad
Q_{abs}=\int_{\Gamma}|(u-w)\cdot n|\,dA.
\]

内膜与基底盖面分开报告，然后汇总完整闭合表面。带符号通量允许正负抵消；
Q_abs 衡量采样界面的局部法向滑移，不能积分后直接当作流失的血量。
原约束冻结旧几何；本诊断在接受后的当前几何上积分，因此也不能用它替代原面片残差检查。
原 MAC 散度接近零、固定腔体积、平均盖面通量为零和逐点无穿透是不同条件。

对线性节点运动，三角面积向量是时间的二次多项式。
诊断用旧、中、新几何的 Simpson 积分核对整个表面的材料通量与 (V_new−V_old)/dt。
当前几何上的单点时间通量 Q_w 可以不等于此体积差；本次差约 0.0312 ml/s。
这属于运动几何的时间离散差异，不能直接解释成实际质量流失。

独立 RT0 速度重构的单元散度严格等于原 MAC 离散散度。
它仅用于诊断，不替换原 IB 插值、模拟速度或流体网格。
其切向分量在单元边界可跳变，表面积分仍须检查数值积分收敛。

## 真实网格结果

使用同一 `phase15_mac128_isovolumic_15ms_v1` 输入，推进 10 个 0.1 ms 步至 516 ms。
默认 3 格基底面片共 237 片；独立 2 格加密检查为 526 → 527 片。
这里加密的是基底压力约束面片，不是将 128³ 血液网格改成另一种网格。
默认宽度仍为 3 格，已有检查点续算保持保存的面片宽度。

当前几何上的独立表面积分采用内膜细分等级 2、3、4，长径向盖面额外细分两级。
下表取最高等级；两个案例的 Peskin 通量在最后两级之间都满足 0.001 ml/s 的积分变化目标。

| 当前表面诊断 | 3 格面片 | 2 格面片 |
| --- | ---: | ---: |
| 内膜绝对相对通量 Q_abs (ml/s) | 4.10905 | 4.10857 |
| 盖面绝对相对通量 Q_abs (ml/s) | 0.975525 | 0.683096 |
| 内膜带符号相对通量 (ml/s) | +0.0253371 | +0.0209061 |
| 盖面带符号相对通量 (ml/s) | −0.0278584 | −0.0214325 |
| 完整表面带符号相对通量 (ml/s) | −0.00252135 | −0.000526451 |
| 完整表面流体通量 Q_u (ml/s) | +0.0286641 | 约 +0.030667 |

盖面 Q_abs 降低约 30%，但内膜诊断值基本不变。
原 IB 运动方程残差的位移 L2 范数约 3e−10 cm，投影速度与材料速度最大差约 1e−6 cm/s。
下一步需处理界面速度与通量的离散一致性，不能只进一步加密基底或收紧 Newton 容差。
此短窗口从已有全局等容状态激活盖面约束，包含边界切换调整；不是生理周期收敛结果。

最高等级 RT0 闭合表面流体通量分别约 −7.34e−5、−1.59e−4 ml/s，
但最后两级变化仍为 0.00579、0.00393 ml/s，未达到 0.001 ml/s 积分目标。
这些小终值不能单独作为已完成保守界面验证的证据。
运动几何恒等式误差约 1e−10 ml/s；固定体积误差约 1e−12 ml；两个检查均无回退。

默认诊断目标为带符号通量 0.01 ml/s、完整表面绝对相对通量 0.1 ml/s、积分变化 0.001 ml/s。
这些是可配置的工程筛查目标，不是源项目生理标准，也不是新的步进接受条件。
两个主动收缩状态均不通过完整表面目标；弱激活预加载检查状态通过。
报告顶层 `passed=true` 仅说明诊断执行和几何/通量恒等式检查成功，
局部质量目标应读取 `surface_mass_audit_passed`，多个状态应读取 `all_surface_mass_audits_passed`。

## 性能优化

原面片缓存要求数量固定；2 格检查中，第 7 步增加一片会重建全部列，约耗时 9.16 s。
现在按面积重叠映射既有压力方向，只对新出现的独立压力方向调用原 GPU 压力投影。
526 → 527 片的实际更新仅调用一次压力投影，耗时 0.0643 s。
保留原始几何刷新基准，累计运动超过 0.1 格仍重建，避免逐步更新掩盖缓存漂移。
映射退化时保留可逆预条件器近似；其数值只用于迭代加速，不进入物理残差或最终结构力。

| RTX 4090、128³、0.1 ms 机械步，同起点 10 步 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 2 格首步，含编译/列构造 (s) | 16.312 | 16.345 |
| 第 7 步面片数变化 (s) | 10.397 | 1.424 |
| 排除首步后的 9 步均值 (s/步) | 2.29596 | 1.33465 |

均值降低约 42%。步时间包含同步后的 EP/ODE、原隐式 FSI 和应变反馈，不含检查点写盘。
该短窗口不能直接外推整个周期。默认 3 格方案此前同窗口约 1.262 s/步。
完整质量诊断单独运行约 0.95–1.64 s/状态，不在常规步进中执行。
独立 2 格普通入口续算已接受 516.1 ms；恢复会重新构造缓存，首步约 16.2 s，不算稳态性能。

58 项检查通过，包括 CPU/CUDA 几何恒等式、MAC 散度一致重构、已知通量、原检查点不变、
联合导数/反力功、缓存新增压力方向、检查点恢复及既有端口/等容/预加载/压力后端检查。
优化前后同一终点节点位置最大差 7.52e−11 cm、源腔压差 1.20e−7 mmHg、
总结构力相对 L2 差 3.41e−8、流体压力相对 L2 差 4.96e−8。
面片压力最大差 0.0661 dyn/cm²；原 AFSI 六个核心 MAC/力学文件逐字节一致，输入检查点未改写。

## 使用方法与剩余范围

```bash
cd /mnt/large2/gjh/AFSEI
source scripts/activate_afsei.sh
python scripts/check_afsei_mac_mass_budget.py \
  --checkpoint results/phase16_mac128_closed_cap_10steps_fast_v1/checkpoint.npz \
               results/phase17_mac128_cap2_native_update_10steps_v1/checkpoint.npz \
  --levels 2 3 4 --write-vtk --output results/my_mass_budget
```

输出每个状态的报告和内膜/盖面 VTK，可查看每面相对通量、绝对相对通量、面积和平均法向滑移。
诊断校验输入检查点散列，不推进电生理、心肌、循环阶段或 RCR 状态。

如需独立复测 2 格方案，须从尚未保存盖面压差的等容状态开始：

```bash
python scripts/run_afsei_closed_cap.py \
  --checkpoint results/phase15_mac128_isovolumic_15ms_v1/checkpoint.npz \
  --patch-width-cells 2 --steps 10 --output results/my_cap2
python scripts/run_afsei.py --resume results/my_cap2/checkpoint.npz \
  --duration-ms 1 --profile --output results/my_cap2_more
```

已有面片压差不能直接改宽度续算。结果位于服务器 `results/phase17_*`，不提交结果或网格。

真实流量—压差—三元素 RCR 和源阶段切换，完成实际 AV 关闭触发及整个周期验证。
