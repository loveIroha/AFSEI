# 同一个隐式 MAC 步内的等容基底反力

本阶段解决第十三阶段独立投影没有推进心肌、没有把反力放入结构残差的问题。
它是可选择的闭合基底/固定体积验证模式，不是完整生理循环或实际端口流量驱动的 RCR。
原 AFSI 的规则 MAC、BE 黏性响应、一次旧速度输运、旧位置 IB 模板及源 EP/GPB/Land 保留。
没有四面体血液网格，也没有外层反复调用完整流固步的迭代。

## 离散方程与源模型

旧位置为 $x_n$，未知位移为 $y$。$S,J$ 为原 MAC 的力扩散和速度插值，
$B$ 为冻结在旧几何上的盖面流量行，$C$ 为同一材料盖面的速度流量行。
$W$ 是 MAC 面速度的体积权重，$\lambda$ 是面片压差（dyn/cm²）。
同一步解位移、源内膜等容控制压力 $p$ 与面片压差：

$$f_s=F_{source}(x_n+y,p)+C^T\lambda,$$
$$f_{fluid}=S f_s-W^{-1}B^T\lambda,$$
$$u=U_{BE}(u_{departure},f_{fluid}),\qquad y-\Delta t Ju=0,$$
$$V_{closed}(x_n+y)-V_{target}=0,\qquad Bu-C(y/\Delta t)=0.$$

最后一式以 $\Delta t/area$ 缩放到位移单位进入同一个 Newton–GMRES。
其雅可比包括原解析被动/主动切线、源内膜 follower 导数、当前腔压列和基底两侧反力列。
完整联合残差使用原机械容差；额外检查真实盖面相对通量范数不超过 1e-5 ml/s。
不在步进后覆盖速度，不丢弃返回的盖面反力。

盖面压力功满足
$P_{cap,fluid}+P_{cap,solid}=-\lambda^T(Bu-CJu)$，
报告同时给出用位移增量和用插值速度得到的约束残差。
源内膜控制压力是本验证模式的载荷未知量，尚不能当作已连接的 3D 出口/RCR 压力。
盖面冻结方式与原旧位置 IB 离散一致；测量体积仍使用更新后的完整内膜和运动基底盖面。

源材料、主动 PK1、Land 应变反馈和接受 AV 关闭后 80 ms 空间张力卸载协议不变。
固定体积目标不逐步更新；RCR 电容状态继续只按假定闭合出口 Q=0 更新。
本入口不会自行宣布 AV 开启/关闭或进入充盈，也不会伪造卸载触发事件。

## 仅左心室的几何处理

闭合模式通过 `MACBasalPorts(..., with_ports=False)` 构造材料三角盖面。
它不需要真实瓣膜或虚拟瓣口圆盘；完整盖面划分为 MAC 尺度压力面片。
真实 128³、13 cm 外箱，默认宽度 3 格，本次共有 237 个面片。
参考基底仍须平面且可由边缘均值作星形扇面；当前盖面允许随材料运动和翘曲。

约束是面片平均相对法向速度为零。积分点流速和材料速度仍可能在一个面片内部不同，
因此绝对点位泄漏不能用几乎为零的净通量替代，更不能宣称已实现逐点无穿透。

## 预条件器与成本

位移主块用单位近似；腔压和盖面压差用有符号小型 Schur 近似。
盖面 Schur 的初始列通过同一个 GPU DST-II 压力投影及原 IB 转移构造，
没有额外 EP、ODE、结构非线性或完整 FSI 推进。
只用于预条件器，不替代真实 BE 黏性响应或最终收敛检查。

首次实现要求积分点面片归属完全相同才能复用。真实基底的微小运动使少数积分点换面片，
每步重建耗时约 4.1 s，带反力步进约 5.40 s。
现在当几何运动小于 0.1 格、面片数量不变且能按至少 80% 面积形成一一对应时，
用积分面积重叠矩阵映射旧的预条件器列。真实当前流量行每步仍重新组装。
超出条件时重建，不修改面片方程、物理参数或接受容差。

时间是同步 GPU 的完整 EP/ODE/FSI/应变反馈步，不含检查点写盘。
短检查不能外推为整个周期固定成本；较大运动时预条件器重建和非线性迭代会改变速度。
本性能窗口从旧等容状态激活新增边界，包含数值边界切换的调整过程；
其压力演化和盖面反力不应作为生理 PV 曲线解释。后续周期应从源 8 mmHg 预加载状态启用闭合边界。
独立验证入口每 50 步及最终/失败时保存检查点，避免每 0.1 ms 压缩全 EP 状态造成额外写盘开销。

## 保存、恢复与验证

沿用自包含带校验和的检查点；新增盖面压力与其接受的旧几何数组，
保存闭合模式和面片宽度。恢复会检查旧几何等于 `previous_x`，
并以源力加盖面反力重新验证保存的结构力。预条件器是运行缓存，恢复后重建。
不同面片宽度不能直接沿用已保存的压差分量；改变它需要单独的投影/迁移处理。

```bash
cd /mnt/large2/gjh/AFSEI

  --resume results/my_closed_cap_10steps/checkpoint.npz \
  --duration-ms 1 --profile --output results/my_closed_cap_more_1ms
```
