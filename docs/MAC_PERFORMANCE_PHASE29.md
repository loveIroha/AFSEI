# 第二十九阶段：减少重复同步与内存操作

保持第二十八阶段的模型和计算方法：原 128³ Cartesian MAC、BE 隐式黏性及压力投影、
一致质量矩阵 PCG、现有 modified Newton–GMRES 与失败恢复、原正交化和验收容差。
源 EP/GPB/Land、主动应力、卸载规律、RCR、基底约束、积分规则、步长和 float64 不变。
没有接入显式流体，也没有增加外层 FSI 迭代。

## 完成的执行优化

1. 图质量矩阵求解的初始有限性、RHS 范数和真实残差合并为一次设备计算/主机读取。
   零初值直接得到 r=b，省去 M*0 的稀疏乘法；不可变质量矩阵在构造时做一次有限性检查，
   避免零初值掩盖 NaN/Inf 算子。PCG 递推、16 步检查块、重算计划和最终真实残差不变。
   装配传递不再对随后直接送入质量求解器的同一 nodal_force 重复扫描/读取。
2. 隐式流体的 response/advance 在已有工作区中直接构造 RHS 和初值，融合点运算与写入。
   省去三个整域临时 RHS 及后续复制。公开速度和压力仍拥有独立存储，不被下一次求解覆盖。
3. 基底压力 lift 直接累加到调用者独立拥有的密度数组，省去三个整域零数组和整域加法。
   联合调用链延后中间 cap 标量检查到质量 RHS/BE/压力验收，省去已验证流体速度的重复扫描。
   公开 lift/reaction/interpolate 默认仍检查有限性；元数据检查始终保留。
4. 压力模式复用腔口拓扑、内膜节点索引、参考积分规则与固定网格坐标。
   每次 prepare 仍更新当前几何、积分点、法向、权重、传递矩阵和压力模式，并验证正闭腔体积。
   表面 stencil 编译为融合的 PyTorch GPU 运算。先检查三角形凸包的原支撑范围；
   全部顶点通过时，非负重心积分点已受同一范围保证，不逐块读回。
   顶点不通过时保留原逐点检查，不因捷径拒绝原先有效的积分点。
   合并外箱边界检查和报告读回；旧 stencil 的数值数组不会被后续准备覆盖。
5. GMRES 用 Arnoldi 必需的作用范数同时检测非有限输出，省去独立 isfinite 同步。
   复用已测量的真实残差范数供循环和报告使用。两次正交化、预条件器、QR、
   estimated/true 检查计划和真实残差判据保持不变；不采用新的 Anderson 或 Krylov 复用方案。

以上是执行优化。浮点融合和运算分组可改变最后几位及收敛路径，不保证逐位相等或迭代次数相同。
