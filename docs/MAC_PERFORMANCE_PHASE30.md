# 第三十阶段：质量图、流体工作区与 GMRES 融合

完成第二十九阶段尚未完成的三类执行优化。继续采用原 128³ Cartesian MAC、
BE 隐式黏性及压力投影、一致质量矩阵 PCG 和现有 Newton–GMRES。
EP/GPB/Land、主动 PK1 与卸载、RCR、阶段组织、材料、基底、积分规则、步长、
float64 和验收容差均不变；没有改为显式流体，也没有增加外层 FSI 迭代。

## 已完成

1. **质量矩阵与传递的图覆盖及融合。** 在原 PCG 迭代块之外，新增零初值、
   非零初值和真实残差重算三个 CUDA Graph。初始化融合有限性、范数、容差、
   Jacobi 初始方向和标量写回；真实残差融合减法、范数和重启准备。
   输入先复制到稳定地址，图再执行；最终解仍为独立副本。
   原检查时点、重算计划、breakdown 检测和真实残差验收保留。
   准备重启工作区不提前推进未知量，也不改变接受条件。
2. **流体内存操作。** BE 压力 RHS 在固定数组中融合构造；DST 的实数扩展、
   复数频域和两块变换工作数组复用。GPU 打包/解包使用 Triton，FFT 仍为
   原 PyTorch `rfft/irfft`，DST-II、特征值、边界条件及原矩阵真实残差均不变。
   正反变换的相邻点运算融合，末次正变换融合特征值除法。
   对外返回压力前复制一次，避免后续求解覆盖已发布状态。
   `SpectralDirichletPressure(..., workspace=False)` 保留原实现供对照。
3. **GMRES 小运算与工作数组。** 每列原有顺序 Givens 更新合并为一次 GPU 调用，
   使用稳健 `hypot`，关闭该核函数的乘加融合以保持原运算分组。
   每个 balanced endpoint 复用 V/Z/H、旋转、小向量、正交化乘积和工作数组；
   跨重启、Newton 修正和物理步使用，包括失败后的新切线恢复。
   V/Z 的每个有效列先写后读，省去整块重复清零；小 H 和 g 仍重置。
   两次正交化、右预条件、QR/三角求解、estimated/true 检查计划和最终验收保留。
   不复用旧 Krylov 子空间或旧解；复用的是存储。

CPU 保留等价的张量实现。工作区归各求解器所有，串行调用，不使用全局缓冲池。
浮点运算执行形式改变可能影响末位，不能承诺逐位相等或所有场景迭代次数相同。

工作区复用需要常驻显存，并不等同于降低总显存：128³ float64 的谱工作区约
96.25 MiB，BE 压力 RHS 另为 16 MiB；GMRES 存储随未知量和 restart 增长。
不同 dt 的 endpoint 分别持有工作区，公开状态保持独立。

本次观测整步耗时减少 **1.10%**，约 0.021 s/步；样本短且耗时范围重叠，
不能作为统计上确定的持续加速承诺。首次准备约 18.54 s，包含编译和图捕获。
两个 800 ms 周期按 16,000 步外推约 **8.39 h**，上一轮约 8.48 h；
这只是收缩期短窗口外推，完整周期耗时及 dt=5e-5 未在本轮测量。

为检查 FFT 工作区是否增加搬运成本，另对同一 128³ 压力逆算进行 CUDA event 短探针：
5 次预热、20 次计时，均与原算子数值对照。
原实现约 2.260 ms/次，当前工作区约 1.977 ms/次，减少约 12.5%。
将工作区改为 FFT 原生轴布局的候选约 2.232 ms/次，因此保留当前布局。
这不是完整流体或物理步的加速比例；60 次压力求解只对应约 0.017 s 的局部节省。

剖析中 `item/tolist` 次数仍为 476/518；本轮没有删除既定的主机收敛决策。
图重放增多是初始化/真实残差纳入图的结果。Python 调用数也不是 GPU 效率指标，
CPU 剖析含异步等待、嵌套调用和工作计费迁移，不能将各项直接相加。
